赛事共享授权操作规范

适用于赛事主办方和受邀工作人员

共享授权只开放指定赛事和已勾选模块。它不会把受邀者加入主办方机构，也不会开放该机构的其他赛事、球队或经营资料。

主办方分发

  1. PC 登录主办方账号，进入“账号管理”并选择“分发账号”。
  2. 选择具体赛事，填写受邀者已验证的手机号和姓名，勾选需要开放的侧边栏模块。
  3. 保存后邀请状态为“待接受”；保存成功不代表对方已获得可用权限。
  4. 将本说明或打印件交给受邀者，并提醒其使用邀请手机号登录和接受邀请。
  5. 主办方可在账号管理修改权限或停用授权。停用后，旧页面也不能继续操作。

受邀者接收

  1. 使用邀请手机号登录 PC。
  2. 点击顶部带数字提示的“赛事邀请”，或打开账号管理查看“待接受邀请”。
  3. 核对赛事名称和授权模块后点击“接受邀请”。手机号不一致时联系主办方修改邀请。
  4. 回到“赛事空间”，打开标有“共享赛事”的卡片；只使用已授权模块。

本人赛事与共享赛事

受邀账号也可以创建自己的机构和赛事。尚无本人机构时，从赛事空间选择“创建我的赛事”并先建立自己的机构。本人赛事与共享赛事会同时显示；返回赛事空间只切换工作空间，不撤销共享授权。

账号安全

  • 受邀者使用自己的账号，不共用主办方密码。
  • 不转发验证码或访问令牌。服务号绑定与赛事授权分别管理。
  • 遇到赛事、手机号或权限不符，停止操作并联系主办方核对。
线下交接不能替代系统邀请和本人在线接受；最终权限以账号管理中的有效授权为准。规范版本：2026-10-06。
