# 公众专业版抽签大屏原型确认板

## 页面结构

单区段、单横向流程，共七个 1920×1080 原型节点：抽签介绍、球队展示、抽签进行、分组结果、发布撤回、链接无效/过期、断网恢复。

## 交互与状态

点击任意节点查看完整原图；查看器支持上一页、下一页、缩放和键盘方向键。节点行为说明覆盖发布、只读同步、撤回、过期和断网恢复。

## 数据字段

只使用公开赛事、竞赛组别、公开球队、抽签阶段、结果和发布状态样例。

## 素材决策

原型图来自 `../prototypes/`；确认板不复制生产素材。

## 素材缺口

无。

## 开发边界

当前七个 `_assets` 包状态均为 `awaiting-user-confirmation`。用户明确确认素材包前，不进入正式大屏应用或公开快照接口开发。
