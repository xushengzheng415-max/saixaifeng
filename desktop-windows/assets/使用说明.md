# 赛小蜂足球应用图标

用于 Windows 客户端。登录页使用用户提供的4167×4167透明竖版LOGO；应用图标使用用户指定的500×500方形图，保留蜂、足球和蜂巢背景，四角半径22%，圆角外透明。

- 当前安装包：`icon.ico`（16/24/32/48/64/128/256 多尺寸）。
- 通用图标：`icon.png`（512×512，圆角外透明）。
- 高清图：`app-icon-square-1024.png`；原图：`brand-original-square.png`。
- 透明品牌图形：`brand-symbol.png`。
- 完整竖版：`brand-vertical.png`；原图：`brand-original-vertical.png`。
- 预览与来源：`brand-preview.png`、`brand-source.json`。

源文件由用户于2026-10-27提供：`E:/Documents/saixiaofeng_football/logo文件/竖版.png`、`方形.png`。仅作尺寸和圆角适配，未重画或改写标准字，不声称SVG母版。可通过`desktop-windows/scripts/build-brand.py`重建。
