## 页面结构

保留现有比赛头部、赛事名称、双方队徽、比分和状态。赛况页在已结束或进行中时渲染一条居中的分钟时间轴：左侧为主队事件，右侧为客队事件，节点按分钟排序；若有半场边界则插入半场节点。未开始时不渲染事件时间轴，只显示“暂无赛况信息”。

首发页先渲染主队的绿色半场球场，再渲染客队反向半场球场。队员以号码圆牌、姓名和位置/角色显示；站位基于真实 `formation` 和首发顺序计算，不把没有坐标的数据伪装成真实热区。球场下方单列“替补阵容”，按两队并列的行结构显示号码、姓名，以及从比赛事件中可推得的换上分钟。

## 交互与状态

- “赛况”：未开始显示真实空状态；已开始/已结束显示事件时间轴；不提供直播、竞猜或写入操作。
- “首发”：没有已发布的阵容时显示真实空状态；有任一队首发时渲染球场与替补区。
- “榜单”：保留现有只读空状态，等待赛事公开榜单数据。
- 返回和底部导航沿用现有路由，不改变公开访问边界。

## 数据字段

- 比赛：`matchDate`、`matchTime`、`venue`、`round`、`status`、双方队名/队徽/比分。
- 事件：`minute`、`type`、`teamSide`、`playerName`、`playerNumber`、`assistName`、`assistNumber`、`description`。
- 阵容：`formation`、`starters`、`substitutes`、球员的 `number`、`name`、`position`、`captain`。
- 替补换上分钟只读取本场 `substitution` 事件；没有该事件时不显示分钟。

## 素材决策

四张截图仅作为结构和视觉密度参考，均不作为生产背景、卡片或图标。正式页面使用 CSS 绘制球场、圆形号码牌、时间轴与卡片；继续使用比赛数据中的真实队徽。比赛事件的进球、换人、黄牌、红牌统一替换为 `oil-icon` 生成的 `football-match-events-v1` 透明 PNG 图标族，原图、切图、洋红底 QA 与语义台账位于 `docs/prototype-assets/` 和 `docs/ICON_ASSET_CATALOG.md`。

## 素材缺口

当前公开数据没有球员实际坐标、评分、身价、年龄、头像或角球/越位/犯规等完整技术统计。因此本次不添加这些参考图中的数据，也不伪造球员场上位置；只按阵型和真实首发顺序做规则化站位。

## 开发边界

正式目的地为 `service-account-h5/tournament-center.js` 与 `service-account-h5/tournament-center-qa-fix.css`。维持“仅开封立洋杯”的公开范围、网页端零 SDK 和比赛数据只读；不写入球队、球员、阵容或赛果。该素材包状态已由当前明确页面调整请求批准，可以开始正式实现。
