# 服务号 H5 公共赛事中心首页

源图：`E:\Documents\sxf-football\service-account-h5\prototypes\public-tournament-home.png`  
尺寸：`393 × 853`

## 页面结构

1. 服务号品牌栏；高度与原型顶部内容区一致，不复制手机状态栏和微信胶囊。
2. 横向赛事分类栏。
3. 焦点赛事大图，保持原型的图片比例、底部叠字和分页圆点。
4. 近期两场比赛摘要，保持左右两栏结构。
5. 赛事动态列表，保持左图右文的连续列表节奏。
6. 固定五栏底部导航，后续页面按原型继续接入。

## 交互与状态

- 分类切换会重排当前公开赛事、比赛摘要与动态列表。
- 点击焦点赛事、比赛摘要和动态，预留至后续的墨刀对应详情页。
- 覆盖加载、空、错误和图片失败；没有默认登录、写入或直播动作。

## 数据字段

- 赛事：公开名称、类别、封面、地点、日期、公开状态、队徽。
- 比赛：赛事、竞赛组别、轮次、开赛时间、主客队公开名称、队徽、公开比分、状态。
- 动态：由已发布赛事和赛程状态生成，不使用虚构评论、热度或用户内容。

## 素材决策

- 墨刀截图、裁片、标注层只用于还原验收，绝不作为页面背景或 UI 裁片。
- 正式默认背景使用服务号已有足球场资产；正式赛事封面优先使用已发布快照中的 HTTPS 图片。
- 队徽使用已发布赛事快照，缺失时由代码显示球队首字占位。
- 16–24px 控件使用共享 SVG / CSS，不从墨刀裁切图标。

## 素材缺口

- 墨刀中的新闻缩略图没有可确认的赛小蜂版权或来源，因此不直接搬运；服务号首页用赛事封面或默认足球场图作为动态缩略图。
- 墨刀的直播、竞猜、聊天、礼物和双币页面按用户要求不实现。

## 开发边界

- 用户已于本轮明确确认：服务号 H5 是公共赛事门户，且视觉必须以墨刀为准。
- 本包只批准首页；比赛列表、未开始/进行中/结束状态、榜单和“我的”按墨刀逐页建立各自的素材包后继续实现。
- 匿名端只读“发布到赛事中心”的快照白名单，不能直接读取赛事、球队或球员业务集合。
