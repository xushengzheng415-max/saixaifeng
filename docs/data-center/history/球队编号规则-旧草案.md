# 球队编号规则

## 编码格式

```
[省份号3位][城市字母1位][序号3位][类型代码2-3位]
```

## 规则说明


| 部分     | 长度  | 说明             | 示例          |
| -------- | ----- | ---------------- | ------------- |
| 省份号   | 3位   | 省/直辖市代码    | `226` = 河南  |
| 城市字母 | 1位   | 车牌字母         | `A` = 郑州    |
| 序号     | 3位   | 该城市第几支队伍 | `001`         |
| 类型代码 | 2-3位 | 队伍类型         | `01` = 一线队 |

## 完整示例


| 完整编号    | 分解         | 含义                |
| ----------- | ------------ | ------------------- |
| `226E00101` | 226-A-001-01 | 河南郑州第1支一线队 |
| `226E00102` | 226-A-001-02 | 河南郑州第1支二线队 |
| `226E00108` | 226-A-001-08 | 河南郑州第1支U8队   |
| `226E00109` | 226-A-001-09 | 河南郑州第1支U9队   |
| `226E00110` | 226-A-001-10 | 河南郑州第1支U10队  |
| `101A00101` | 101-A-001-01 | 上海静安第1支一线队 |
