# 数据中心知识库

状态：2026-09-29 用户已确认按统一方案实施，并要求所有项目内数据机制依此开展统计。

本目录是赛小蜂足球数据板块的正式共享知识库，与源码同版本维护。适用于 H5、PC、小程序、云函数、导入、导出、榜单及后续新功能。

## 权威基准

1. 当前用户指令与 `../PRODUCT_RULES.md` 的有效产品边界。
2. [统一方案](../DATA_CENTER_STANDARD_PROPOSAL_2026-09-29.md)：身份、关系、归属、统计及质量基准。
3. [数据契约](CONTRACT.md)：当前实现的接口与集合约束。
4. [统计入口登记](INTEGRATION.md)：每个入口的实现和迁移状态。
5. [上线与验收](RELEASE.md)：部署依赖、环境初始化、测试与实际边界。
6. [球员卡积分与等级](PLAYER_CARD_POINTS.md)：PC、H5、小程序统一的职业生涯积分规则；实际接入状态见登记表。

旧方案涉及专业版、数据包付费门槛的内容，以现行“赛事流程免费”规则为准，不能重新引入开通或支付限制。

## 不可绕过的规则

- 球员永久 ID 不随球队变化；球队历史成绩不等于当前球员生涯总和。
- 历史归属使用比赛当时的球队与参赛关系，不反查当前球员库推断归属。
- 新统计入口必须调用统一服务或统一统计模块，不在页面新建算法。
- 每项指标必须说明范围、单位、来源、公式、审核状态、去重和缺失策略。
- 未知、部分记录、未采集、无权限、失败与真实零值分开表达。
- 修改、撤销和身份修订需要影响范围、版本与对账；导出与页面使用同一版本。
- 数据量超过读取预算必须报明确错误或分批处理，禁止静默截断或把失败转成零。
- 组织与公开范围由服务端校验，跨组织身份继承不等于继承原组织私有资料访问权。

## 开发交付

改数据功能之前读取本目录及现行产品规则；完成后更新 `INTEGRATION.md`。指标变化更新版本及测试。新增入口登记其授权、数据来源、统计范围、调用模块、质量反馈和验收场景。

本地检查命令：

```text
node tools/sync-data-center.mjs --check
node tools/test-data-center.mjs
node tools/check-data-governance.mjs
```

共享源码位于 `cloudfunctions/dataCenter/shared/`。其他云函数的 `data-center/` 是部署副本；只能通过 `tools/sync-data-center.mjs` 更新。禁止在副本里单独改规则。
