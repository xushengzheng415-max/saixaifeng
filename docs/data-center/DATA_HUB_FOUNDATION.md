# 平台数据总站基础合同

日期：2026-10-23。数据基准归档于正式本地仓库；用户已在地基验证后授权继续前端开发，先接平台运营中心。历史“暂停页面”指前一实施阶段，不再作为当前暂停指令。

## 职责与真值

平台运营中心是球队与球员数据的统一运营入口，不另建球队库、球员库或第二份统计真值。权威实现仍为 `cloudfunctions/dataCenter/shared`，页面及其他端按服务端授权读取。

球队长期档案来自 `teams._id`；球员长期档案来自 `players._id`。参赛名单、比赛阵容、赛果及事件保留当时归属。不能按姓名、球衣号码、当前球队或当前账号合并历史身份。

## 测试与未知来源

沿用统一 `statistics.mjs.synthetic`：synthetic、isTest、syntheticDatasetId、syntheticKey、source=ai_fixture、originType/dataKind 的 test/virtual/synthetic/demo 标记。目录排除测试球队及测试球员；真实球队下的测试球员也排除。测试球队下未打标球员同样不进入正式目录。比赛聚合继续同时核对赛事、比赛、双方球队及涉及球员，不按名称猜测来源。

历史关系、转会及身价快照另检其来源；关联测试球队的记录不进入正式历史。来源未能核定、档案缺失、读取失败、记录不完整与明确零值分别返回，不把失败转成空表或0。

## 读取接口

`dataCenter` 新增三个候选 action，均再次认证并限定平台负责人，拒绝公开和赛事子账号；不允许客户端通过自报权限、orgId 或任意统计范围扩大读取。

| action | 输入 | 主要输出 |
|---|---|---|
| hubCatalog | kind=teams/players、keyword、pageSize、cursor，可按teamId筛球员 | 服务端游标分页目录、nextCursor、扫描与排除说明、accessScope、dataVersion；球员含已核验当前球队名称 |
| hubTeamProfile | teamId | 球队档案、当前正式球员数、正式生涯及年度统计、约球生命周期与友谊赛年度数据、版本与完整度 |
| hubPlayerProfile | playerId | 球员档案、当前队、正式生涯统计、双来源历史关系、转会、有效估值快照、近期比赛及五维证据 |

档案接口固定正式生涯口径，不接受赛事、球队、日期范围来悄悄截断为本届数据。新接口不返回电话号码、身份证号、人脸材料、登录账号或经营财务资料。其他端暂不直接开放平台 action；后续以各端已有授权适配同一底层服务，不发放平台权限。

### 一万份档案容量与分页

用户确认容量目标是存放一万名球员的资料与关联历史，不是万人并发。目录默认50、最大100条/页，按稳定_id游标读取并仅投影必要字段；筛选球队兼容teamId/teamCode。单页扫描预算1000条，达到预算仍返回有效续页游标，不把全是测试记录的一页误判成数据结束。跨类别、跨筛选复用游标明确拒绝；不返回整库档案或把客户端翻页当作数据库分页。

隔离内存夹具10000条：1000条测试球员及500条测试队下未标记球员排除，8500条正式记录经86次游标读取完整取出，0重复、0漏读。增加当前球队名称投影后最大响应43,552字节。此测试只证明分页正确与载荷有界，不代表线上延迟、存储额度或并发压测结论。

比赛、事件、球队关系会随历史增长。统计查询继续有明确预算超限错误，不静默截断。长期的批量重建、可失效汇总缓存、赛事事件索引和后台对账任务属于下一层容量建设，不能用一万份目录测试替代全历史性能验证。

### 球队生涯与年份

正式赛事按比赛当时的球队ID聚合，不能用当前球员库累加替代。年份按实际比赛时间与Asia/Shanghai归档，不按赛事创建、球队入驻或当前年份分配；无实际日期进入undated。年度正式场次、胜平负、进失球加undated可与生涯总计逐项对账。年度计算复用同一批已授权事实和统计引擎，不重复扫描数据库，也不在页面重新计算。

### 日常约球与友谊赛

球队档案另接friendly_matches与friendly_invites。邀请、报名中、待赛、完成、取消与未知状态分开；邀请数量不等于比赛场次，报名不等于实际上场。完赛但比分缺失的胜平负和进失球保持未知，不能默认0:0。对手球队或参赛球员缺稳定身份时，仅作为球队自报记录与待核验数量，不能冒充已完整核定的比赛指标；已知测试比赛、测试双方或涉及测试球员整条排除。

保留既有isOfficial含义，即“转入本队正式战绩”的自报标记，但它不等于赛事组委会审核归档，仍不进入官方赛事排名。友谊赛与正式赛事总计、年份、完整度和版本独立；本轮不把友谊赛纳入原正式球员积分或身价规则，不追溯修改既有业务数据。

已将friendlyMatchCenter.teamFriendlyStats的本地候选接入同一readFriendlyTeamHistory读取器，去除limit(1000)和缺失比分归零；保留原成员鉴权和旧字段适配，并增加完整度、年度与数据版本。该函数尚未部署，不得以源码变更宣称旧线上入口已修复。新旧数据读取共用完整游标与预算告警，后续按入口登记及实际发布读回逐个收口。

## 时间字段

`registration.registeredAt` 只读明确的 `platformJoinedAt` 或 `firstRegisteredAt`；没有时为 null，status=unknown。档案创建时间单独返回 `profileCreatedAt`，不得冒充首次入驻。加入当前队的时间、再次登记、赛事报名和账号注册时间均不能替代首次入驻。

不根据1052份创建日期批量补写入驻时间。今后登记入口写入新字段、历史证据核验及存量回填属于独立实施项，需准确列出入口并验证幂等；本轮不执行数据库迁移。

## 球队关系与转会

历史适配同时读取 `player_team_memberships.validFrom/validTo` 和 `player_team_history.joinedAt/leftAt`。只有球队、起止时间、结束状态明确一致的跨来源记录才能合并证据；缺失时间保持未知。不同球队有效期重叠、多个开放关系、当前球队与开放历史不一致分别报告冲突，不自动选第一条或修改归属。

转会业务记录与入离队事实分开，不把时间相邻的入离队自动配对成转会。首次入驻不是转会；待确认不是已完成。

数据中心既有同机构转会流程补强：发起时从同一授权服务冻结当期评估、数据版本、估值算法及口径；未评估仍保留pending/null。确认时同时维护两套关系事实与当前指针，检查旧成员/历史记录属于同一球员及原队。重复确认幂等，不改写比赛、名单、事件、正式成绩或冻结估值。跨机构流程继续明确拒绝，不能绕过授权及资料交接。

其他既有登记/转队入口尚未全部完成同样的冻结接入，因此不能宣称全平台所有转队流程已闭环；新增写入口按统一合同收口，不从读取接口静默回填旧记录。

## 身价与五维

保留已确认估值权重与金额刻度，不把卡牌随机属性作为真实能力。单球员查询的比较样本从同一授权赛事事实建立，先排除测试及不完整样本，再在内部计算，不将同组私人档案返回调用者。表现质量只与同位置样本比较。

历史趋势读取匹配球员、算法版本、统计scopeKey、完整度、数据版本及时间的快照。历史生涯积分使用 `careerPoints`，不能使用身价质量分 `index`；缺积分快照的趋势明确标记估计。缺快照集合可标记not_recorded，权限/网络/索引错误必须失败，不能伪装没有历史。

五维表现为：竞技积累、表现质量、出场稳定、成长趋势、荣誉成就。优先展示统一服务已核定因子及其原始证据；估计因子不能冒充真实轴值。年龄、位置稀缺、赛事级别或应援不能为凑满五轴替换这些指标。

2026-10-25 起五维统一为 `football-career-five/3`：按 0–10 分输出并保留一位小数，**封顶 9.5 分，不评满分**（五维是同组别的相对分位，组内第一也不显示 10.0，避免被读成绝对实力）；`ceiling` 字段随结果返回。原始值只作附注，页面按已核定轴绘制闭合雷达面。竞技积累取核定积分因子，表现质量取进球/90 分钟，出场稳定取核定出场因子；成长趋势优先取可信积分快照对比，无快照时用已留存积分明细的近段与前段场均积分对比，样本不足返回null；荣誉成就取已归档正式赛事的统一奖项汇总（MVP 50、金靴 40、金手套 40、最佳阵容 40），按每 10 分折算 1 分后同样受 9.5 上限约束。任一维度缺失或估计时保持 null 并把整体标记为 partial，不补 0 也不补中性值。

赛事奖项完备性按应有赛果场次判断：已取消和轮空占位场次没有赛果，不计入 `totalMatches`，否则整届赛事永远无法归档；未归档的正式赛果仍会阻止评定。生涯荣誉按各届赛事的完整赛果重算，不能再用球员参赛子集或球队授权子集代替全赛事数据；历史数据中同一人存在档案 `_id` 与球员编号两种阵容引用时按别名集合匹配。

青少年数据保持原授权边界；总站输出不展示其金额、总指数或段内指数，保留允许的星级。身价不是成交价、收费项目或可兑现资产。

## 验证与发布界限

隔离验证覆盖测试标记/测试队下球员、同名不同ID、平台权限、固定生涯口径、双来源历史去重/冲突、日期来源、缺失快照、异常读取、完整分页及预算超限、版本稳定、转会幂等和原赛果不改写。

共享副本由sync-data-center同步；运行test-data-center、test-data-hub、test-player-card-unified、check-data-governance和finish-data-change。测试数据只在内存夹具，不进入生产。

函数代码发布、运行配置修改、数据库建表或迁移、真实业务读回和页面上线分别登记。历史地基阶段不代表页面已接入；当前实际接入见下条发布记录。上线不代表所有历史数据已经补齐。
