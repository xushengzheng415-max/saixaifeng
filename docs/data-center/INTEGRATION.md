# 数据入口登记

此登记是新增或修改数据功能的必填交付物。当前检查为本地代码，不代表生产已切换。

| 入口 | 权限与范围 | 统一实现 | 状态 |
|---|---|---|---|
| PC 数据中心 | 机构所属球队/主办赛事；平台所有者全平台 | dataCenter → shared/service + statistics | 已实现、本地验证 |
| 小程序数据中心调用 | 工作空间授权球队/主办赛事 | getMiniWorkspace.dataCenter → shared/service | 已实现、本地验证 |
| H5 公开数据调用 | 已发布赛事、已公开比赛、正式结果 | webLoginApi.publicDataCenter → shared/service | 已实现、本地验证 |
| 小程序球员详情 | 已授权球队的球员贡献 | shared/service，同一指标引擎 | 已接入 |
| 小程序球队赛事数据/导出请求 | 本队、赛事、组别；免费赛事流程 | shared/service；同一版本 | 已接入 |
| 小程序赛事正式名单指标 | 本队、赛事、组别 | shared/statistics；缺失为未知 | 已接入 |
| PC 球队赛事球员指标 | 本队、赛事、组别 | dataCenter 服务 | 已接入最新 main 的独立提交版本 |
| PC 成绩中心 | 主办方赛事；排名沿用当前赛事规则 | shared/reader 完整读取、事件修订合并；提供 dataCenter 响应 | 已接入 |
| PC 球员详情与编辑 | 原业务鉴权 | shared/service；编辑只改原始档案，不手填累计统计 | 已接入 |
| PC 名单/球员媒体指标 | 原业务鉴权 | shared/service，不再单独计算 | 已接入 |
| 小程序赛事榜单、历史参赛展示 | 原业务权限 | shared/service；积分和排序来自共享 standings | 已接入 |
| H5 旧门户快照、应援榜单 | 公开发布范围；应援与竞技指标分开 | 公开历史展示继续保留；新增竞技统计走统一接口 | 兼容保留，不能作为新竞技统计模板 |
| 跨机构转会 | 双方授权与隐私交接 | 当前返回明确审核错误 | 未开放自动执行 |
| 历史身份批量合并、旧库迁移 | 数据审计后按批次审核 | 禁止按姓名自动合并 | 尚未执行生产迁移 |

每个新入口还需登记：指标版本、原始集合/字段、正式或暂定模式、查询分页、覆盖率、修订传播、各端及导出一致性、业务验收与部署证据。

应援次数属于用户互动数据，不能作为进球、出场或赛事积分的替代。训练、教务等经营数据保持现有授权边界，未来关联球员时需登记来源并定义独立指标。
