## 比赛补录换人规则

平台规则对话框只改所选竞赛组别的换人方式、上限、窗口及换回开关，规则从已生效版本继承并追加历史；名单、报名截止、身份校验和其他组别不经此操作改写。换下名单由本场当前在场状态派生；换入名单由当前组别限制及本场 stable ID 阵容派生。PC 补录和裁判服务写入经同一 `substitution.mjs` 校验，比赛事件版本冲突须刷新重录。历史换人异常保持可见，不靠规则新版本伪造修复。

PC 比赛详情和共享换人状态会忽略阵容快照中的 `null`／非对象空槽，避免空槽参与球员字段读取；真实球员对象缺失或重复 stable ID、以及不能唯一核对的旧换人记录仍会阻止新增换人并返回具体原因。

真实比赛需要重新换回的组别设置 `substitutionMode=free` 与 `substitutionReentryAllowed=true`；只有“人数无限”但不许换回的组别用 `free/false`。未设置/不完整的规程显示待核对，不按赛事名、老年组或球队名称推断。详情中的正式比赛复核警示只供补录查因，不改写旧阵容或裁判提交快照。

此登记是新增或修改数据功能的必填交付物。当前检查为本地代码，不代表生产已切换。
