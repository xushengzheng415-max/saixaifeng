## 球员卡积分统一口径（2026-09-30）

PC、H5、小程序后续球员卡统一遵循 [PLAYER_CARD_POINTS.md](PLAYER_CARD_POINTS.md)：`2×出场+首发+floor(分钟/45)+封顶进球加分`，45 分银卡、100 分金卡，规则版本 `football-player-card-points/1`。这项规则已确立，但 `starts` 指标、统一积分服务、历史卡级迁移及三端接入尚待实施；上表 C 端现有 10/20 场规则属于旧实现，不得称为新积分。

应援次数属于用户互动数据，不能作为进球、出场或赛事积分的替代。训练、教务等经营数据保持现有授权边界，未来关联球员时需登记来源并定义独立指标。
