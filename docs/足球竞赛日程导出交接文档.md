# 赛小蜂足球竞赛日程导出交接文档

> 交接目的：将赛小蜂篮球赛事中心已经确认的“竞赛日程”导出规范迁移到足球平台。足球端应复用数据口径和输出约束，但字段、组别、赛制和球队名称必须以足球业务为准。
>
> 状态：交接规范，待足球端实现与验收后转入当前状态记录。

## 一、交付目标

足球后台的“竞赛日程”需要同时支持：

1. 页面查看；
2. A4 竖版/横版预览；
3. Excel 导出；
4. 浏览器打印及另存 PDF。

四个出口必须从同一份标准化赛程行数据生成，不能分别拼接出不同版本的赛程表。

## 二、数据边界

- 只读取已经保存并发布的赛程数据。
- 抽签、赛程和导出只使用审核通过的参赛名单。
- 当前组别、阶段、轮次、分组、球队、场地和状态筛选要作用于页面、预览、Excel 和打印。
- 如果要导出该组全部场次，先清除筛选条件。
- 调整日期、开赛时间或场地不得改变场序。
- 赛制、分组或出线规则变化导致重建时，必须明确提示会重建对阵、场序和赛程。
- 正式竞赛日程不能把未排场次静默删除；容量不足时保留“未排”状态并提示原因。

## 三、标准输出字段

导出和打印使用以下八列，顺序固定：

| 列 | 字段 | 展示要求 |
|---|---|---|
| A | 日期 | 统一为 `YYYY-MM-DD` 或项目统一中文日期格式；连续相同日期可合并 |
| B | 时间 | 24 小时制 `HH:mm` |
| C | 轮次 | 如“第1轮”“半决赛”“决赛”“9—12名排位赛” |
| D | 组别 | 如 U8、U10、公开组；不得与抽签小组混用 |
| E | 分组 | 如 A组、B组；无分组时留空 |
| F | 比赛队 | 显示“主队 vs 客队”；淘汰赛来源显示“场序13胜者”等 |
| G | 场地 | 正文显示简短场地号或场地名；完整场馆名放在表头摘要 |
| H | 场序 | 当前竞赛组别内从 1 连续编号，居中显示，是跨模块关联键 |

足球端可以增加内部数据字段（比赛 ID、阶段 ID、依赖场序、状态等），但不得改变正式输出列顺序。

## 四、表头与页脚

表头至少包含：

- 赛事名称；
- 竞赛组别；
- 赛程日期范围；
- 场馆名称；
- 当前导出方向（A4竖版/A4横版）；
- 制表日期。

页脚或备注区固定保留：

> 比赛时间与场地以主办方最新发布的竞赛日程为准。

如赛程包含未排场次、临时调整或场地冲突，应在表头或备注区明确标注，不得用空白行掩盖。

## 五、合并、排序和分页

- 日期只合并当前连续行，不跨越不连续记录。
- 同一日期内连续相同轮次可合并；跨打印页时应拆分合并区域，并在下一页重复值。
- 默认排序：日期 → 时间 → 场地 → 场序；如产品已有确定排序，以已保存赛程顺序为准，但页面、Excel、打印必须一致。
- Excel 必须设置打印区域为 `A1:H最后一行`，并将列头行设置为重复打印标题。
- 续页必须重复列头；标题区只在第一页出现，页眉或重复列头应能识别赛事和组别。
- A4 竖版为默认；队名较长、场地较多或列内容较宽时切换横版。
- 页面方向、打印方向和 Excel 页面设置必须由同一个方向状态控制。

## 六、文件命名与格式

Excel 文件名必须包含赛事名、文档类型和方向：

```text
赛事名-竞赛日程-A4竖版.xlsx
赛事名-竞赛日程-A4横版.xlsx
```

Excel 工作簿建议：

- 工作表名称：`竞赛日程`；
- 冻结或重复列头；
- 日期、轮次合并为真实 Excel 合并区域；
- 场序列窄且居中；
- 比赛队列获得最大宽度；
- 长队名换行，不用极小字号硬塞；
- 打印边距、纸张方向、缩放比例与 A4 预览一致；
- 创建者和品牌信息使用赛小蜂足球，不得保留篮球项目名称。

## 七、排赛数据必须先通过的约束

导出只是已保存赛程的投影，不能替代排赛校验。发布前至少检查：

1. 同一场地、同一日期、同一时间不得有两场比赛；
2. 同一球队连续比赛必须满足最少休息时间；
3. 比赛必须完整落在合法时间段内；
4. 组别只能排入适用场地；
5. 淘汰赛不得早于其依赖的前置比赛完成；
6. 同一标准场拆出的子场与整场之间遵守资源互斥；
7. 关键场次是否必须使用主场地，应由赛事规则明确；
8. 冲突提示要指出具体球队、场地、时间或依赖场序。

## 八、实现建议

建议足球端拆成以下可测试模块：

| 模块 | 职责 |
|---|---|
| `normalizeScheduleRows` | 从已保存比赛生成八列标准行 |
| `groupContinuousRows` | 计算日期和轮次的连续合并区间 |
| `buildScheduleSheet` | 生成页面、预览和 Excel 共用的表格模型 |
| `openSchedulePrint` | 打开独立 A4 打印预览并调用浏览器打印 |
| `exportScheduleXlsx` | 按当前方向生成 Excel，并设置打印属性 |

不要从 HTML 的偶然文本反向导出；优先从标准行数组直接生成 Excel，确保换页、合并和筛选行为可控。
