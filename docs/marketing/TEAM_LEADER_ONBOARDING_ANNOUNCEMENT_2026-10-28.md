# 领队群入驻公告：成稿文案 + 竖版公告图（2026-10-28）

用途：在赛事领队微信群推动「领队注册/认领球队 → 球员建档 → 赛事名单 → 材料补交 → 比赛日阵容 → 电子参赛证」的配合。

事实口径（只能按这些写，不能扩写未上线能力）：

- 依据 `docs/PRODUCT_RULES.md` 第三章 3.4.1/3.4.2、第十八至二十章，`docs/PLAYER_REGISTRATION_EVENT_IDENTITY_STANDARD.md`，`docs/handoffs/TEAM_ROSTER_MATERIALS_FLOW_2026-10-26.md`。
- 完整 Word 报名表上传成功后，系统直接创建正式球员并生成本届名单，不需要领队二次确认入库或提交名单。
- 只有报名表登记的领队或填写手机号的主教练，用同一已验证手机号账号才能认领球队；未认领不影响主办方查看已导入的球员和名单。
- 导入生成的球员身份状态为「待人证核验」，未通过人证核验不能进入比赛阵容、电子参赛证和官方个人统计。
- 先提交赛事大名单，再按主办方附加要求补材料（证件/保险按竞赛组别配置，进入球队待办与通知）。
- 电子参赛证按赛事与组别要求启用：现场由裁判当面核对，扫码不自动代替核对；青少年现场不用二维码，由助理裁判按名单照片核验；没带手机走名单人工核验。
- 现场顺序：主裁判与双方负责人报到 → 提交首发及替补 → 第四官员初审 → 主裁判确认 → 助理裁判分边逐人核验 → 全员通过后开赛。

## 一、成稿版（通用，可直接发；无赛事专属信息）

【赛小蜂足球 · 领队入驻指引】比赛临近，球队和球员请统一到平台上管

各位领队：

本届比赛的报名、名单、材料和上场，全部在「赛小蜂足球」里完成：认领球队 → 球员档案 → 赛事名单 → 材料补交 → 比赛日阵容 → 电子参赛证 → 赛果数据。微信群以后只用来沟通，不再用来收表和接龙。

**一、对球队的好处**

1. 报名表一次上传，系统自动生成正式球员和本届名单，不用再逐个填表、不用二次接龙。
2. 每一步都有留档：谁在什么时候交的、审到哪一步都能查；赛后修改球队日常资料，不会覆盖已审核或已完赛的记录。
3. 球员档案跟着人走：换赛事、转队保留原球员编号和历史，球员卡、形象照做一次长期用。

**二、对球员和家长的好处**

1. 手机扫码就能登记，不用装 App；一个家长账号可以关联多个孩子。
2. 姓名、证件号、球衣号、位置、身高体重、形象照一次录全，下次报名直接带出。
3. 电子参赛证就在手机里，随时能出示，不用提前跑去找组委会开证明。

**三、对赛事的好处（也是大家最直接受益的地方）**

1. 赛程、比分、积分榜、技术统计同一套数据，现场录入即出结果，不用赛后人工汇总。
2. 集合时间、场地变更、材料补交通知直达球队待办，不再在群里刷屏找不到。
3. 现场核验有据可查：谁上了场、谁做过核验、裁判签字时间都能追溯，有争议时拿得出依据。

**四、请领队配合这 5 件事（完成后在群里接龙回执）**

1. 认领球队：用报名表登记的那个手机号注册并认领，一个手机号只能对应一个主账号。重复注册会导致看不到球队。
2. 补全球员：把全队资料和形象照补齐。未通过身份核验的球员，不能进入比赛阵容、电子参赛证和官方个人统计。
3. 材料按时交：证件、保险等按本赛事组别要求在截止日前上传，不要拖到赛前一天。
4. 比赛日按时交阵容：赛前提交首发＋替补；现场流程为主裁判与双方负责人报到 → 提交阵容 → 第四官员初审 → 主裁判确认 → 助理裁判逐人核验。
5. 配合参赛证核验：现场出示电子参赛证，由裁判当面核对；手机没电或没带，按名单走人工核验，不因此取消资格。

**五、时间节点**

- 球队认领：以组委会通知为准
- 全员资料与形象照：以组委会通知为准
- 证件／保险材料：以组委会通知为准
- 首场比赛：提前到场报到，具体时间见赛程

说明：电子参赛证按赛事和组别要求启用，本赛事以组委会通知为准；青少年组现场由助理裁判按名单照片核验，不必出示二维码。

有问题在群里 @【对接人】或直接联系组委会【联系人／电话】。

## 五、发送建议

- 节奏：第一天发短版＋竖版公告图，第二天发长文并 @所有人，第三天开始催接龙。长文一次发出容易被刷掉。
- 配图：用本文档对应竖版图，或报名管理「邀请球队」导出的邀请海报与入驻指引，同一套口径，不要另外自造图。
- 群里只讲结论和动作，不解释后台逻辑。被问「为什么非要注册」，回答一句：不注册就看不到自己的球队和名单，赛前核验也走不了。
- 不要承诺平台尚未给的能力，例如「每场自动刷新新参赛证」「实名后永久免核验」「所有组别都能扫码上场」。
