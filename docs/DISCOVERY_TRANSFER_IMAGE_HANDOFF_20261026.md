# 发现赛事与转会市场图稿交接

日期：2026-10-26。状态：ImageGen 视觉探索图稿及本轮口述要求整理；未开发、未部署、未处理真实转会。

## 本轮用户明确要求

- 发现一级栏目仅为动态、赛事、约球。球队招募放到动态，不放进赛事卡片或转会市场。
- 赛事卡片做好封面、赛事资料与状态；提供赛事中心和转会市场两个入口。赛事中心复用已有赛事链接。
- 转会市场属于发现内的赛事入口，不新增底部一级导航。窗口倒计时跟随对应赛事；当前只支持依托赛事窗口办理，不为赛事外球队创建独立转会链路。
- 市场开放所有球员的可展示资料查询，不要求先主动挂牌。公开范围仍按原授权；青少年不公开货币估值及指数。
- 搜索可查询球员、位置、球队、技术数据和身价；展示实力榜、上升最快榜。具体实力指标、排序、比较窗口和缺失数据规则待确认，图中顺序和涨幅均是示意。
- 球员查询下方放最新转会信息卡片。左侧为球员资料，中部为原球队队徽、箭头与新球队队徽，右侧为部分隐藏的最终成交金额，例如 ¥8,***。
- 查询球员详情后提供我想租借和我想转会入口，组织方式借鉴足球经理游戏的资料查询与报价流程。

## 复用入口与现行规则

已核对小程序 discover.js 现有赛事中心入口：`/pages/public-tournament-center/public-tournament-center?hash=event-<tournamentId>`。正式接入必须传当前真实赛事 ID；不能用图稿中的示例赛事构造线上记录。

转会与租借具体生效、三轮谈判、合同、自由球员与线下款项处理以 `TRANSFER_CENTER_PLAN_2026-10-26.md` 及现行已确认产品规则为准。原球队谈判、主办方审核与球员本人档案权限分开；不因本图稿添加球员同意节点或线上支付。

“本赛事”标签仅表达图中所选赛事上下文。是否必须两队参加同一赛事、跨赛事归属等原方案待决项，不由图稿自动定案。窗口关闭时可浏览公开资料，办理能力由服务端按已确认规则核验。

## 数据与设计限制

- 人物、球队徽标、统计、涨幅、成交金额、估值和倒计时全部为生成式示意，非现网数据。
- 成交金额来自最终完成记录；算法估值来自既有统一服务，二者不得混用。
- 部分隐藏金额只是本轮明确要求，准确遮挡位数、不同角色可见范围、服务器投影与审计策略待开发前细化。不能把完整金额下发后只在前端盖住。
- 实力榜与上升最快榜仅完成视觉位置，未新增统计算法或任何能力评分；示例技术数据不进入正式统计。
- 生成式图稿为不可编辑栅格，中文字形、头像和图标可能有细微误差；实现时需使用原始品牌素材、共享SVG和原生文本组件。实际交付保存完整原图与提示词。
- 当前预览包里的旧交互原型仅作历史探索；2026-10-26本图稿为本轮层级与版式参考，不能把旧“转会意向主动挂牌/球员同意/球队招募在市场”等探索直接作为需求。

## 本轮交付边界

本轮未修改小程序业务页面、后台合同、估值算法或云函数，没有新增真实球员、赛事或转会。图稿展示不是正式接口、实时倒计时或真实转会功能验收。

## 同日后续修订与接收端

以下修订替代上文旧图稿的球员查询及详情入口，旧文件保留作探索追溯。

- 市场页只保留球员查询的筛选入口，不在入口页直接堆球员查询结果。进入后按球队、组别筛选，位置为补充筛选项，查询结果进入球员资料。
- 球员详情两个按钮使用用户指定文案：我想租借他、我想买断他。买断在办理协议中对应正式永久转会，不表示线上购买或支付。
- 接收端为当前原球队管理者；收到申请球队报价后可查看、接受、还价或拒绝，不把该端误做为球员个人确认端。
- 授权原队内部可见具体本轮报价，公开已完成成交信息仍部分遮挡最终金额。协商轮次规则以转会中心方案为准，图稿不重新定义轮次。
- 还价发给申请球队重新确认。双方同意同一版条件后进入主办方审核；尚未通过并完成交接时仍显示当前原球队归属。
