## 原型区域与正式实现

| 原型区域 | 正式实现 | 数据与行为 |
|---|---|---|
| 标题、城市、搜索、记一场 | discover.wxml / discover.wxss 的 market-page 范围 | 城市及记录权限沿用现状；搜索只匹配已展示的公开球员，不冒充全库检索 |
| 三项范围 | market-scope | 赛事、竞赛组别沿已有接口；全部时间保留原图入口，点击明确暂未开放 |
| 绿茵官宣 | spotlight | 独立干净球场背景，姓名、队徽、价格代码渲染；无成交时保留同位置和比例的空状态 |
| 双榜并排 | rank-panels | 身价、上升最快各预览最多2行；“查看”展示服务端已返回的榜单，未额外推算排名 |
| 球员查询 | query-shortcuts / player-card | 保留球队、组别、位置入口；球队入口未接入会明确提示；组别/位置沿既有行为 |
| 最新转会 | trade-row | 球员、原球队→新球队、价格同一行；赛事来源在下方；金额按现行服务端公开状态展示 |
| 赛事转会中心 | transfer-cta | 继续回到有上下文和权限的赛事内办理，不复制报价/合同/审核 |

标题、卡片、金额、按钮与图表均用代码。原型裁片没有进入产品。没有修改动态、赛事、约球的业务，不修改后端、数据库、身价算法或价格公开权限。
