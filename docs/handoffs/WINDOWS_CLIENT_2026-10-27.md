2026-10-27，用户确认先制作 Windows 客户端。范围为主办方 PC 后台，不包含平台运营后台、手机 App 或离线业务系统。

## 结构与发布边界

源码位于 `desktop-windows/`，以 Electron 45.0.0 和 electron-builder 26.18.1 构建 Windows x64 NSIS 安装包。默认加载 `https://www.sxffootball.cn/admin/`，菜单可重启切换既有测试地址 `/preview/admin/`。两个入口分别使用独立登录资料，但共用现有正式云端服务；不复制数据、权限或统计机制。

本次只新增客户端，不修改 PC 页面、小程序、H5 或云函数，不部署服务器，不改变主办方 PC 的预览验收流程。平台长期分支当前有其他会话的未提交修改；本次未切换共享分支、未提交或推送平台分支。客户端新增文件需单独审阅、从权威 main 按既有流程集成，不能整体合并平台分支。

## 实现

- 安装向导、可选安装路径、桌面与开始菜单快捷方式、单实例。
- 沿用微信扫码、手机号验证、机构与赛事权限；远程页面没有 Node.js 或本地文件 API。
- 下载保存、打印、缩放、全屏、前进后退、刷新及失败重试。
- 正式/测试入口与登录资料隔离；切换测试时提醒共用正式后端。
- 网页联网更新；外壳目前通过新安装包更新，没有静默自动更新。
- 安装包尚无组织发布者签名，不作为已签名的对外发行版本。
