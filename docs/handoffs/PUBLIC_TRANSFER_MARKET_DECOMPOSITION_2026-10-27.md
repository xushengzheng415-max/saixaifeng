## 交互与状态

- 四栏目切换保留既有状态；转会页聚合公开信息，不承接报价、合同及审核。
- 城市、赛事、组别、周期影响列表/榜单范围；“全部赛事”只是查询范围，不能代表全部赛事共有一个转会窗口。
- 搜索与筛选由真实公开接口提供；当前转会搜索在本地正式代码中禁用，需接口到位后启用。禁止输入后不生效。
- “筛选查询”和球队/组别/位置标签打开同一个面板，避免两套独立条件。标签为当前条件快捷入口。
- 点击官宣或成交条目打开可公开的详情；只读展示已执行、允许公开的成交事实。还价、未审核报价不生成“已转会”官宣。
- “查看资料”打开公开资料。现有赛事内球员详情包含办理上下文，不能仅凭 playerId 绕过原有权限。
- 我的赛事转会中心：有明确赛事上下文时进入；否则让用户选一场自己可办理的赛事。报价继续校验身份、参赛关系与窗口。
- 未接入：明确显示“暂未接入”；加载：骨架；空列表：“暂无转会记录”；失败：保留筛选与内容并提供重试；分页：加载中/重试/已到底。禁止失败显示空或把空字段写成0。
- 搜索防抖与旧请求失效；筛选变更重置游标；重复点击不重复跳转。交互区建议至少 44×44 CSS px。
- 底栏复用正式身份限制：当前主办视角的球队入口限制不能被重画导航绕过。

## 数据字段

以下是展示契约建议，不是新增接口已经存在的声明。

| 对象 | 字段 | 约束 |
|---|---|---|
| 公开成交 | transferId / tournamentId / tournamentName / divisionId | 保留稳定ID和赛事来源；不按姓名归并 |
| 球员 | playerId / displayName / position / portraitUrl | 仅服务端准许公开字段；不暴露手机号、证件、监护关系 |
| 流向 | fromTeam.id/name/crestUrl / toTeam.id/name/crestUrl | 历史成交取当时快照，不能被现球队覆盖 |
| 成交 | type / executedAt / publicStatus / publicPriceText | 服务端确认已执行；类型区分租借与买断；公开金额由后端脱敏 |
| 身价 | valuation.value / currency / asOf / version / completeness | 参考估值与实际成交金额分开；沿用数据中心口径 |
| 排名 | rank / metricKey / scope / period / delta / asOf | 成人/青少年及不同组别不得默认混排；身价与实力不是同一指标 |
| 走势 | points[{date,value,completeness}] | 真实估值历史；样本不足显示缺口，不复制上升曲线 |
| 列表 | items / nextCursor / hasMore / serverNow | 后端分页，不拉取全部赛事私有报价再由前端拼接 |

公开接口不要下发完整成交价后让前端用星号遮盖；真实金额只向有权的交易双方和审核端返回。跨赛事聚合不自动扩大每个赛事的公开范围。测试球队、测试球员、测试交易不得进入真实榜单或成交列表。

## 素材决策

- 原图与 11 张裁片均为参考，不是生产素材。文字、价格、排名、筛选、导航、卡片及曲线全部代码实现。
- 生产背景候选引用现有 `miniprogram/images/runtime/stadium-tech-bg.jpg`，已查看，是干净球场背景，与官宣原图的真实草地质感有差异，未承诺像素一致。
- 球员形象照和队徽来自正式授权业务数据；图稿合成人像与虚构队徽只用于参考，不从截图抠成真实记录。不改既有头像完整展示规则。
- 搜索、位置、列表与底部四项矢量复用项目 `miniprogram/images/icons/`。发现导航继续复用整个正式组件的已采用品牌素材。本轮未下载新图标，不新增页面私有图标库。
- 下拉和前进箭头复用原生选择器/现有链接表现；方向采用代码“→”。原图赛事名称前的装饰奖杯可省略，信息提示用文字，不为装饰另造图标。
- 所有共享路径均是相对当前素材包的仓库引用。压缩包按仓库相对结构同时携带《共享引用清单.json》登记的9个共享原文件，解压后保留目录即可解析引用；这些是交付副本，不是另建正式共享库。单独移动页面素材子目录会失去相对引用。

## 素材缺口

1. 缺独立透明主角形象照及正式队徽：实际实现由真实数据提供；暂无授权素材就用已有默认形象，禁止使用生成稿冒充。
2. 跨赛事公开成交列表、焦点排序、搜索及榜单接口未在发现页接入。后续先定公开字段、权限、分页与完整度，不从私有合同/报价数据前端聚合。
3. “上升最快”图中表现为近7天身价涨幅；该口径为探索方案，未确认前不写死算法。此前“实力榜”不自动等于本图“身价榜”。
4. 陈晨在图内两处球队不同、人像重复：原图生成瑕疵已登记，生产按 playerId、快照统一；不为了复刻错误另造球员或关系。
5. 原图所有参考数据均为虚构。下阶段才做真实390×844和360×800渲染、中文溢出、长队名、胶囊安全区及交互验证；本次没有执行正式页面视觉验收。
