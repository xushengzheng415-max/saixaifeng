# 服务号二维码当前账号提醒 — 2026-10-15

用户反馈本机存在旧登录记录时无法确认二维码对应哪个账号。二维码显示前通过现有getCurrentAccountProfile读取当前服务端自然人账号及已验证手机号，以手机号尾号明确提示当前账号。昵称仅在本地账号ID与服务端ID一致时展示；手机号昵称不重复显示完整号码。自设微信号不在接口返回中，不使用OpenID/UnionID尾号冒充。

提供切换账号入口，清理当前主办方会话及关注缓存并停止二维码轮询和待执行跳转，不清理另一标签页的平台管理员会话。账号读取失败或身份切换时不继续展示旧二维码。原关注确认和第三方微信冲突校验复用既有服务，不放宽绑定权限。
