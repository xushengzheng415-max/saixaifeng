# 球队详情头像显示修复（2026-11-01）

状态：本地候选，待正式/测试发布；不修改业务照片或数据库。

## 原因与修复

用户指定球队排查时共46名球员，44人有云照片引用，44个不同引用均能在该球队云存储目录找到对应文件；另2人没有照片引用，也没有明确的工作人员关联可复用。不记录个人姓名、证件、真实文件地址或访问凭据。

TeamDetail原先把尚未解析的cloud://文件编号直接交给img。浏览器报错后，playerAvatarErrors按球员ID永久记失败；后台将photoUrl替换成有效HTTP临时链接，也不能解除这个标记，导致有照片仍显示姓名圆形占位。

新增共用PlayerAvatar.vue，赛事球队、工作人员和普通球队名单统一使用：只把HTTP、受支持的本地/图片数据地址交给img；云编号沿既有零SDK getFileUrl解析。解析过程不阻塞名单首屏；加载失败可重试，旧请求/旧img错误不能盖住新URL，组件销毁后忽略迟到结果。照片完整contain展示，背景透明、无圆形框；真正缺图显示破折号。继续复用已部署uploadFile及现有临时链接缓存、在途去重与赛事权限，不新增读取范围，不按姓名配图。

## 验证

- tools/test-player-avatar-browser.cjs：46人合成名单在44个云请求悬而未决时仍全部可见；44张解析后显示，2个缺图保留；img不接收cloud编号；HTTP失败/解析失败重试、旧图片报错隔离、透明contain通过。所有业务请求均拦截为合成数据，不写真实报名记录。
- 运行方式：启动/admin/本地dev服务5197端口；配置SXF_PLAYWRIGHT_MODULE后执行node tools/test-player-avatar-browser.cjs。临时HTML夹具仅本地创建，结束自动移除。
