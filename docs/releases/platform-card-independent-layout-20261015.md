# 三档卡片独立排版修复

日期：2026-10-15。源码提交：`4d350bad`，分支：`codex/platform-ops`。

原因：工作台原先默认启用保存时同步三档排版，保存、切换档位及整套预览都会调用排版复制接口，导致单档字体、颜色、位置、人物构图和徽标设置覆盖另外两档。

修复：移除自动同步开关；保存当前卡、切换档位及预览仅保存当前模板。新增独立“同步排版”操作，确认框列明来源、两个目标档位及覆盖内容；取消不写入，确认后使用原有授权接口复制排版，各档背景、遮罩保持原设置。

验证：`npm run build` 与平台独立边界检查通过。`node tools/test-player-card-independent-layout-ui.cjs` 通过：铜卡独立保存；银卡切换时保存不影响其他档；整套预览保留铜银金三种颜色；取消同步不写入；确认才复制且保留素材；不切换活动模板。全部使用隔离后端适配器和虚构样本，不修改真实卡面。

部署目标仅 `https://pingtai.sxffootball.cn/`，版本 `20261015150814-4d350bad`。正式上线以部署脚本27个文件的HTTP及SHA-256读回一致为准。本次不部署云函数，不推断或回写用户此前被覆盖的真实排版。
