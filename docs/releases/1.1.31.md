# 1.1.31 球员详情顶部完整球员卡

2026-10-16。用户要求将小程序球队球员详情顶部的头像替换为球员卡。

## 实现

只修改pages/team/player-detail四份页面文件及发布元数据。详情返回后独立调用既有utils/player-card.read（getMiniWorkspace.playerCardRead，player-card-dynamic/1），沿原账号、工作空间、teamId、playerId授权读取当前活动模板/展示选择。动态场景复用components/dynamic-player-card及统一渲染器，展示宽300rpx、高430rpx；历史已就绪整卡地址使用aspectFit完整展示。移除头像外框、光晕和额外号码圆标，不自排卡内文字、人物、号码或队徽，不根据页面积分或卡色推断等级。

资料和竞技数据保持原teamPlayerDetail来源，卡片独立加载不阻断整页；暂无卡/更新中/失败/无权分别显示。无卡或读取失败保留已授权照片aspectFit，失败提供重试，无权不显示卡及照片。动态绘制错误使用现有组件内重试，整卡图片失败回到照片和重试。动态组件原预览、历史整卡图片预览保持。12秒读取超时、在途请求去重、离页/账号/工作空间迟到响应隔离，重新可见重读版本。
