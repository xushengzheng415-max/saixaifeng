# 规程草稿组别删除后不再重建

用户报告演示赛事空白组别删除后仍出现，截图同时提示“组别已删除”和“已根据竞赛规程生成组别草稿”。

共用DivisionManagement加载时每次按规程建议补缺失组别，未读取已有suggestions_applied消费状态。演示、测试和正式使用同一组件，包含规程识别建议的赛事都可能触发；删除权限和空组别保护本身没有因此失效。

在自动生成前检查regulationRecognitionStatus，已应用时不再自动创建；新识别明确回到suggestions_ready后仍可生成新建议。保留原建议与应用记录，不删历史规程，也不放开已定版、有报名、抽签或比赛关联的删除限制。

6个隔离源码检查通过：首次生成、删除缺失草稿、刷新后全空、重新识别建议、无权限、无建议。没有删除或更改真实赛事资料，无云函数修改。

本次先发布preview；正式/admin保持原资源，等待当前任务明确的正式发布授权。
