# 自动发放与基础样式（2026-10-16）

## 用户确认

首批样卡确认后直接发放所选名单，自动显示批次进度，不再要求手动加载全部动态卡。基础金银铜在样式库直接可见，分别显示实际发布状态。

## 实现

平台保留首批24人预览及可选更多预览。首批成功后确认按钮可用于全部所选稳定ID；仍绑定已发布样式修订，不能混用过期模板。确认后以原10人批次自动调用服务端，显示已处理/成功/失败；不预生成全员静态PNG。

webLoginApi仅差量更新playerCardWorkflows.cjs。原平台负责人鉴权、候选范围、真实来源、等级、原照片及套系原子授予保持。逐人确认的业务问题记入任务failures并继续，网络、读取、事务及版本错误仍暂停且不推进未知项。issueStatus提供持久结果；retryIssue仅复制原失败ID建立幂等子任务，重新核对现有范围及资格，保留原任务历史，不恢复撤销授权。页面关闭后可从发放记录继续，不承诺独立后台调度。

基础旧卡直接显示铜银金各自发布状态；已发布图与草稿图分开。只读生产回查：基础铜卡v3有活动指针；基础银卡/金卡publishedVersion=0、无活动指针。没有激活模板、迁移名单或替运营人员发放真实卡片。
