# 成绩册组别布局与独立导出

成绩册从多组连续铺排改为竞赛组别标签切换，一次显示当前组的个人奖项、最佳阵容及球队奖项。颁奖依据折叠；组别页显示当前正式赛果完成数，并提供“打印本组”“导出 PDF”。本组尚有比赛未形成正式赛果时，操作禁用；已完成组别可在其他组别仍未完赛时独立导出。整届打印沿用全赛事完成条件。

单组输出复用原A4打印数据，包含个人和球队奖项、最佳阵容、积分及颁奖依据。浏览器本地生成JPEG压缩的A4 PDF。未修改奖项评定算法或真实比赛数据。

本地隔离样例核对：已完成组别的按钮可用、未完成组别按钮禁用；单组PDF为2页A4，渲染后查看中文、表格与分页正常，压缩后约240KB。正式与测试发布及线上资源读回待完成。
