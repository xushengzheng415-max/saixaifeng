# 1.1.30 球队球员库读取修复

2026-10-16。用户手机球队球员库报“getTempFileURL:fail fileList的元素如果不是对象，则必须是字符串”，整页无法进入。

## 原因与修复

teamPlayers原默认读取整卡。playerCardReader在dynamic=false时调用exportCard，得到已解析cardUrl并标记static-export，但后续仍把不存在的fileId加入临时地址转换，SDK拒绝整个请求。现直接保留已解析、经原导出授权/版本校验的HTTPS整卡URL；其他静态卡只转换本环境有效永久文件ID，坏文件、单卡读取/导出异常和批次地址转换失败分别返回failed，不伪装无权限或无照片，不阻断其他卡片。

teamPlayers增加严格布尔includePlayerCards=false，只在原空间权限、球队归属核验及原名单读取之后跳过不必要的制卡、积分和素材读取。原卡片客户端不传该字段时继续兼容原行为，动态协议不变。球员库页面使用此名单模式，由onShow统一加载，进行中请求复用；点击重试正确清空错误并显示加载，成功清除旧错误。球员库资料状态、完整度、正式名单和参赛资格保持原服务边界。
