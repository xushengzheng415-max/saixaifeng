# 1.1.37 海报队徽水印与左侧组合对齐

2026-10-17。用户保留大队徽背景方向，指出水印仍过重，左侧队徽与队名排版不协调。

水印尺寸及表头裁切保持，不透明度由12%减至5.5%。左侧队徽改96rpx，队名改36rpx、与组别组成纵向文字组并与队徽垂直居中；调整间距和大名单标题留白，避免队徽紧贴标题。Canvas同步160px前景队徽、56px队名、组别基线及标题/状态/人数下移；工作人员起点增60px，以保留分区间隔。人数继续为次要单行，所有卡面、工作人员前置及卡种排序保持。

复用实际app.wxss和既有只读18卡/3工作人员的单一原生工程，390px逻辑视口队徽49×49、文字组高44，中心差0.15px、标题距队徽17px，背景opacity=0.055。实际Canvas导出1200×4370并视觉检查，原名单海报/工作人员回归及WXML检查通过。云接口仍为隔离回放，不宣称真实手机网络验收。
