# 邀请海报三套视觉模板（2026-10-26）

用户反馈首版海报过于简陋，要求提供多套好看的海报。本次只更新邀请海报和入驻指引的视觉层，不更改邀请接口、手机号登录、人证资料处理或未完成的附加材料流程。

- 绿茵赛场：足球、草坪与体育场主视觉；大标题，底部白色赛事信息和扫码票面。
- 红金荣耀：奖杯与红金灯光；居中标题、左下信息及右下扫码卡。
- 蓝色竞技：蓝色赛场和运动光线；左侧足球、右侧独立信息区和扫码卡。
- 弹窗提供三种可切换样式；同一邀请码生成邀请海报及相同风格入驻指引，切换样式不重新创建邀请。下载文件名包含样式名。
- 长赛事名平衡换行，避免单字落到下一行；长地点、组别自动换行并增高画布。二维码不染色、不裁剪，源文字仍由代码动态绘制。

底图由内置image_gen生成，项目文件和最终提示词见[素材说明](../design/team-invitation-v2-assets-20261026.md)。本地隔离Canvas渲染已导出并逐项查看三张邀请海报及入驻指引；示例码不可扫码，不代表真实手机报名链路已重测。

三模板、二维码范围、长文本、无效样式/版本与图片失败回归及Vue组件编译通过。生产构建、PC预览部署与HTTP/摘要结果在此追加；当前尚未发布正式PC，不部署后端或上传小程序/H5。
