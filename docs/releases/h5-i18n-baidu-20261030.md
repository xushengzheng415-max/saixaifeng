# 服务号 H5 一键英文化（百度翻译）

- 日期：2026-10-30，Asia/Shanghai
- 范围：`service-account-h5/` 全站 HTML；后端 `webLoginApi` 新增 `translateUi`

## 行为

- 默认中文；右下角固定 `EN` / `中文` 切换，写入 `localStorage`（`sxf_h5_lang`）
- 英文模式批量调用 `translateUi`，服务端按文案哈希缓存到 `ui_translation_cache`
- 姓名等业务字段可用 `data-i18n-skip` 跳过；纯拉丁文不送翻

## 后端

- 新增 [`cloudfunctions/webLoginApi/baiduTranslateUi.cjs`](../../cloudfunctions/webLoginApi/baiduTranslateUi.cjs)
- 入口：`action=translateUi`
- 凭据环境变量（只读键名）：`BAIDU_TRANSLATE_API_KEY`/`SECRET_KEY` 或 `BAIDU_TRANSLATE_APP_ID`/`SECRET`（及常见别名）
- 差量发布：线上包 overlay → `check-referee-backend-package` PASS → `fn code update --deployMode cos`
- 回下载：`baiduTranslateUi.cjs` 存在，`index.js` 含 `case 'translateUi'`
- 探针：`{"success":true,"translations":{"我的服务":"My Service","正在读取":"Reading"},"cached":0,"translated":2}`

## 前端

- 新增 [`service-account-h5/i18n-runtime.js`](../../service-account-h5/i18n-runtime.js)
- 16 个 HTML 均已注入 `?v=20261030-i18n1`
- 正式 hosting：`service-account-h5/`；`me.html` 含脚本；`i18n-runtime.js` HTTP 200 / 9486 B
