# 未登记球员与比赛质量分离（2026-10-16）

## 用户确认

未登记到该场首发或替补名单、也没有稳定ID实际事件关联的球员，按本场未出场处理，不计该场比赛积分，不属于球员异常。已登记替补且完整记录中没有实际换入的，沿用0出场/0比赛积分。整场阵容或事件缺失仍保留为比赛数据质量问题，不能扩大成全平台每个球员的异常。

## 统一实现

- aggregateStatistics新增participationPolicy=recorded-participants/1，按稳定球员ID登记比赛关联。来源未知/测试来源只影响实际记录涉及的球员，不用当前球队或姓名推断历史参赛。
- playerCardScope由共享snapshot模块统一组织个人覆盖和问题范围，私有单人/批量/发放以及公开摘要复用；未登记者可确认0比赛指标，无关比赛不出现在个人处理清单。
- 真实事件已关联该球员，但本场阵容/分钟缺失或冲突的，继续待处理。读取失败、身份不存在、测试身份、权限不足、应援扣账不完整仍阻断，不转换为0。
- 数据中心全范围质量查询继续展示缺阵容、事件未完整、事件未关联等问题，比赛事实未被自动补造、删除或置零。
- 玩家已获卡级保留、积分参数、100分权益、照片授权及发卡服务端复核保持原规则；没有修改任何生产数据库记录或替用户发卡。
