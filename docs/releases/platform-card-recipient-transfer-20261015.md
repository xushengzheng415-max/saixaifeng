# 球员卡分层选择与核查

日期：2026-10-15。源码提交：`5b9468da`。独立平台分支：`codex/platform-ops`。

## 功能

- 发放窗口左侧待发放、右侧本次发放；赛事→球队→球员逐级勾选，另有当前球队与球员视图。
- 全平台适用样式可勾选全平台根节点；赛事等限定样式始终以原服务端候选范围为边界。
- 整组加入、按稳定ID去重、搜索后勾选仅加入匹配项；右侧逐个移除、批量移回及清空。已加入的球员从左侧移走。
- 等级未核定等不合格候选不可加入；核查按钮在抽屉中打开原数据中心球员核验，自动定位稳定playerId。关闭后重新读取资格并保留仍有效的选择。
- 缺少球员档案的名单关联与竞技等级核查分开反馈，不按姓名自动关联、不手改分数或等级。

目录使用既有dataCenter.catalog受控投影，资格、动态预览、发放事务继续使用既有工作流。没有新增云函数或数据库迁移，本次不替运营人员发放真实卡面。
