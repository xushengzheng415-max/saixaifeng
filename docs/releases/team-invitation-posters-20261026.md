# 球队邀请海报与入驻指引（2026-10-26）

范围：按用户选择先交付邀请海报和入驻指引。组别附加要求、大名单补件、保单OCR与动态参赛证等新流程另行整体验收，不混入本次发布。

## 实现

报名管理“邀请球队”复用现有createTargetedRegistrationLink返回的同一正式版二维码和链接，增加海报预览、“下载邀请海报”“下载入驻指引”，保留复制链接。海报按真实赛事名称、起止日期、地点、当前已开放组别排版，不绑定主办方当前选中的组别，报名截止以球队选择组别的报名页为准。

两个PNG均使用代码排版，不调用AI生成文字图。长名称与地址自动换行、扩展画布；二维码加载失败或缺失时显示明确错误和重新生成入口，仍保留可用链接。关闭、重新打开或切换结果时，旧绘图异步结果不会覆盖新邀请。没有更改姓名、手机号、身份证、照片处理或后台邀请授权规则。

## 验证与发布

本地隔离回归覆盖正式码约束、两个海报复用同一码、入驻步骤、通用组别选择、长文本、自适应高度与图片失败；两个组件及页面编译通过。Edge无界面浏览器已实际渲染PNG并查看画面，示例码明确不可扫码，不代表真实云端邀请/报名已验收。

当前拟发布到PC预览，尚未覆盖正式PC。后续追加实际源码提交、构建及HTTP/资源SHA-256；不部署后端或上传小程序/H5。
