# 1.1.33 小程序球员卡大名单海报

2026-10-16。用户要求球队大名单海报中的球员使用完整球员卡展示。

## 实现范围

小程序正式名单查看页增加“生成海报”，进入球队分包roster-poster。沿原officialRoster按team/tournament/division及当前工作空间重新核验，名单只使用snapshot.playerIds，稳定ID去重并保留缺失历史成员的待核对项；不从整队库补人。已审/确认/锁定显示正式名单，审核中、退回和草稿保留真实状态。未生成本届名单不自动拿球员库代替。

utils/player-card.batchImages沿原playerCardBatchRead并关闭动态协议，分3人、最多2批同时读取后台当前展示卡的兼容完整PNG；沿原权限、活动模板、玩家资料和卡库版本校验及派生成卡缓存。海报只等比缩放完整卡面，不在页面重新排列卡内人物、号码、队徽、文字或等级，不修改比赛统计或竞技积分。

新海报使用三列完整卡阵、深绿金色边界、低透明度放大队徽水印、球队及赛事/组别名称、名单状态、人数、原teamMembers中登记的教练/领队/队医等工作人员。仅投影姓名及职务，不显示手机号、证件或私人账单；管理账号不凭管理员身份混入教练团队。24名球员/12名工作人员一张，任一超出均分页保存，所有稳定成员不截断。

卡图加载渐进显示进度；失败可重试并阻止导出，无权成员不展示图片，明确暂无卡成员使用完整照片/姓名和“暂无球员卡”标识。名单、工作人员读取失败均有恢复入口。预览和保存都通过同一Canvas2D实际合成，宽1200px，高度按当页内容计算，完整卡PNG保持300:430比例。补齐getImageInfo本地相对路径归一化、图片回调超时，离页/账号/空间变化后的迟到结果不显示、不预览或保存。相册失败提示微信设置。

本轮实现小程序入口和海报，PC原RosterPosterModal未修改或发布；没有新增后端接口、激活卡模板或修改业务档案/参赛资格。后端制卡沿已部署兼容服务按需派生缓存。

上传曾被开发工具ignoreUploadUnusedFiles过滤新增页面，报WXML file not found；仅重置文件/编译缓存仍复现。现project.config.packOptions.include精确包含新海报目录与布局工具，保留其余原打包过滤设置，重新上传以实际成功回执为准，没有清理登录/授权/业务缓存。
