# 1.1.09 手机比赛管理体验版

日期：2026-10-15。AppID：wx57164cca8676f411。发布目标：微信开发/体验版本，正式版不更新。

## 最终交互

- 比赛按状态、组别、日期及球队筛选；赛果区分待复核、退回、归档及人工已录入，取消场次不混入，未知比分不转0。
- 赛事详情同日一次一场，左右滑动查看同日全部比赛。
- 只保留“上传裁判表”，统一识别阵容和事件；核对后选择“仅保存阵容”或“确认赛果”。前者不要求填写赛果，后者明确结束比赛。
- 未打钩默认替补；圈号本身忽略，只提取其后的进球分钟，不保存进球顺序字段。规则在核对页可修改后重识别。
- 手动首发/替补复用原单场阵容的球场卡槽、选卡面板及完整球员卡；按主客队切换，取消四段重复长名单。无成卡或图片加载失败仍可按号码和姓名选人，未授权照片不下发。

## 数据与边界

名单、阵容人数、替补上限、重复球员、授权、事件版本、纸质报告签名及裁判锁定依服务端现有流程核验。球员卡使用同一活动模板及标准渲染器，不改变模板、积分和级别；卡片照片是已授权卡面可见像素投影。没有按真实样图自动改写赛果。
