# Windows 客户端 v0.2.2：圆角图标与更新标识

> 历史记录：用户随后授权发布；真实联网验收发现Electron空响应URL兼容问题，已由v0.2.3修复并发布。当前版本与最终回读以 [v0.2.3发布记录](windows-client-0.2.3-20261027.md) 为准。下文“待确认”保留当时准备阶段状态，不作为当前状态。

用户提供 `E:/Documents/saixiaofeng_football/logo文件/方形.png` 作为应用图标，要求四角更圆润，并要求后续新版本有更新标识。

## 已完成的客户端

- 图标保留用户方形图中的蜂、足球和绿色蜂巢背景，等比缩放，四角半径为边长22%，外侧透明。原图保存于 `assets/brand-original-square.png`。登录页继续使用既有竖版标志。
- 窗口标题显示当前版本。菜单及登录页可手动检查更新；启动时及运行期间每6小时自动检查，关闭客户端不运行后台任务。经验证的新版本在菜单、登录页与Windows任务栏显示更新标识。
- 清单只接受官方域名下、与版本匹配的x64安装包，校验版本、大小、说明及SHA-256格式，限制响应大小与请求时间；失败不显示「已是最新版」。已发现的新版本不因后续断网丢失标识。
- 用户点击更新可看说明并下载，完成后核验本地文件SHA-256，再提示退出客户端后安装；不自动运行EXE。0.2.1及更早版本没有检测代码，需要先手动覆盖安装0.2.2，后续版本才能提示。
