# 报名模板队服颜色与赛事组别

原报名Word模板保留服装A/B空格，但没有原生颜色下拉；下载方法也没有传入赛事及组别名称，因此始终留下通用空白。

现在下载时接收当前赛事名称和当前竞赛组别名称，直接填入页头并用于文件名。没有固定活动名称或固定组别；原始模板仍保持通用。文件名过滤操作系统保留字符，正文通过XML文本节点写入以转义特殊字符。

运动员和守门员A/B的球衣、球裤、球袜共12格生成原生w:dropDownList；选项直接引用registrationKitColors.KIT_COLOR_OPTIONS现有17色，显示标准名称，OOXML值使用现有HEX。默认“选择颜色”表示未填写，不默认为白色。原有六项运动员A/B导入沿用现有字段，先精确匹配标准色名/HEX再兼容历史自由文本，避免深灰、银灰、皇家蓝等被较短别名误识别。守门员6格本次提供标准选项供填写与原表保存，现有后台守门员独立配色字段尚未接入自动导入，不宣称已保存到球队库。

当前赛事长名样张已生成，结构回读确认12×17选项、标题上下文、标准名颜色完全一致；运动员六色导入核对一致。使用文档技能render_docx.py渲染三页并逐页查看；照片和队徽原生占位及责任书保留，无新业务数据写入。不修改责任书法律文案。
