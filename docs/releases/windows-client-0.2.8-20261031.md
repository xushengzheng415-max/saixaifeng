# Windows 客户端 v0.2.8：后台下载 + 重启静默更新

## 背景

2026-10-31 用户反馈：更新必须手动点「检查更新」，且体验像重新安装。既有流程虽已用 NSIS `/S` 静默安装，但仍需先确认才开始下载。

## 修改（仅外壳）

- 启动与定时检查发现更高版本后，自动后台下载并校验；任务栏显示进度。
- 下载完成后弹出「更新已准备就绪」，点「立即重启更新」后关闭客户端，静默覆盖安装并自动重新打开。
- 菜单/登录页状态区分：可更新 → 正在下载 → 重启更新。
- 「页面 → 刷新」同址强制重载（0.2.7）一并保留。

## 验证

- `npm test`：17 项通过。
- 打包后正式/测试烟测各 8/8，`version=0.2.8`。
- 安装包 `SxfFootball-Setup-0.2.8-x64.exe`，122,431,595 字节，SHA-256 `ace817167db4e8b917f4d5d8cc6986af18f91cd1015b38e2a5bba61eacd67fbb`。

## 发布与线上回读

- 仅发布 `desktop/windows/`：`publish-0.2.8` → `desktop/windows`，`--entry latest.json --verify`，2 个文件上传成功。
- 线上 `latest.json` 版本 `0.2.8`，SHA-256 与本地一致。

## 说明

- 已安装低于 0.2.8 的机器：仍需手动点一次「检查更新」或覆盖安装本包，之后新版本才走后台下载+重启更新。
- 底层仍是完整安装包静默覆盖，不是差量补丁；用户侧不再操作安装向导。
