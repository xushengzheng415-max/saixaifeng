# 1.1.34 大名单海报重排及白框修复

2026-10-17。用户真实手机反馈大名单海报无设计感、卡片后有白框，卡片间距错乱。

## 原因及最终实现

原海报播放器使用通用.card。正式app.wxss为.card设置白底、16rpx圆角、20rpx margin、24rpx padding和阴影，因此透明PNG四周被白底填满、三列宽度额外膨胀。上版隔离项目仅用了简化app.wxss，未覆盖实际全局样式，漏测该冲突。只读核对目标球队现有18份完整导出PNG，透明四角均为RGBA alpha=0，文件本身不需要抠图或重新上传。

海报全部改为rp-独立样式，播放器无背景、边框、圆角、阴影、margin或padding，完整卡图保持透明和300:430比例。加载中不再先堆人物照片冒充卡片，改为深色骨架、姓名和明确状态；仅明确暂无卡时沿原照片回退，失败/无权及保存门禁保持。

版式采用深松绿底、轻微斜向条带、弱化队徽水印、明晰赛事/球队/组别层级、真实人数主视觉、浅荧光绿强调及轻微错位完整卡阵；删除旧证书式细金边。卡内文字、人物、队徽与等级不修改。新增roster-poster-paint仅负责整张PNG在海报中的平移/等比缩放/轻微旋转，以及页面周边信息与背景，页面/Canvas均使用同一布局参数和配色。保留本届快照范围、24球员/12工作人员分页及已有授权服务，无新后端或统计机制。

## 验证边界

从生产只读取得该球队19份最小球员资料、18人已审核快照、对应现有导出PNG及队徽，不写名单、档案、模板或制卡记录。实际云接口在原生隔离项目中继续模拟；素材为真实卡图和只读快照，教练/队医部分仍为隔离夹具，不能把导出样张当作正式发布给球队的业务海报。

复用同一原生工程，完整复制生产app.wxss与实际页面/布局/绘图工具。390×844下18张图全部ready，.rp-player实际background=rgba(0,0,0,0)、padding=0、margin=0、radius=0，未命中.card，失败阻止导出且重试恢复。真正Canvas导出1200×3832 PNG，已逐图查看透明背景、排列及周边信息，无卡片裁切。专项增加全局类名冲突防回归、加载中隐藏人物照片、布局边界；原正式名单及数据中心13组治理通过。真实手机网络/耗时仍待体验包验收，未声称性能改善。
