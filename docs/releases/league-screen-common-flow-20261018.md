# 联赛投屏与共用流程

用户反馈联赛大屏错误显示A组；确认演示流程与真实建赛共用，只有数据来源不同。

共用大屏按format渲染联赛签位顺序、混合制联赛+名次来源淘汰树、淘汰树和分组，不以单列表猜成A组。控制台读取保存快照判断真实确认状态；点选/排位时降为未确认；结果确认后同步league/cup/hybrid协议。专业及通用投屏声明赛制和确认依据。没有新增演示专属业务分支，未写真实赛果或名单。

抽签总览在所有组别均确认后显示“赛程设置”，直接进入整届赛事的日期、开赛时间和场地配置。以完整组别列表判断，不受当前筛选影响；状态读取失败、读取中或无组别时不显示，不自动编排比赛。演示和真实赛事共用入口。

本次增量构建和线上资源回读待完成；未增加或运行业务测试。
