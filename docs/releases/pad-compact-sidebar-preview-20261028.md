# 平板收起侧栏与紧凑布局修复

2026-10-28，用户真机截图反馈安装版重新出现固定侧栏，并明确要求保留左上角小按钮呼出菜单、内容铺满、尽量减少上下滑动。沿既有授权发布测试站 /preview/admin/。

## 范围与原因边界

原实现只通过屏幕宽度、横屏和触控媒体条件启用适配。截图与官网样式读回表明不能继续只依靠这些条件；没有在 vivo 真机采集媒体值，不把媒体不匹配当作已取证的唯一设备原因。

- 新增 tabletLayout.js：识别现有 APK 已附加的 SxfFootballPad/0.1.0 用户代理，在挂载 Vue 前设置显式布局标记。原生客户端固定横屏，因此即使接鼠标/键盘、媒体查询不匹配，也保持平板布局。普通浏览器继续沿用原媒体条件；此标记仅控制布局，不授予角色或业务权限。
- 全局平板 CSS 与导航组件共用标记，移除组件内重复媒体判断；屏幕布局切回普通桌面时关闭抽屉。
- 侧栏默认收起，小菜单按钮44×44，抽屉仍使用原 currentNavItems 与权限过滤、激活和跳转。
- 缩短页头、外边距、赛事空间封面、控制台强制最小高度。竞赛页四项概览保持同一行，压缩表格留白，保留16px正文和至少44px主要点按区域。三组代表性记录一屏显示，长列表仍滚动，不用 overflow:hidden 隐藏业务记录。
- 本轮只修改 main.js、平板布局工具/样式/导航组件及检查脚本；未改统计、权限、后台数据、云函数、小程序或服务号。APK、包名、签名与更新清单保持0.1.0，无需重装。
