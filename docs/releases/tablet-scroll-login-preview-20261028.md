# 平板报名页滚动遮挡与竖版LOGO登录页

2026-10-28，用户真机截图反馈报名管理页排版重叠，并确认登录页左侧也应使用既有竖版LOGO。本轮在已授权的测试发布范围内修复，目标仅`/preview/admin/`。

## 原因与修正

- 当前交付是同一管理后台的平板网页版，继续使用官网域名和测试路径；没有生成安卓APK。域名无需因布局适配而更改。
- 上一轮检查漏掉报名管理独立路由的滚动状态和较窄、较矮的浏览器视口。页面内`teams-context-header`仍吸顶，和新增系统菜单形成双层固定区域；专业报名页的组别工具栏也有绝对定位，其中一条平板覆盖选择器把同一元素的两个类误写为后代关系，导致覆盖未生效。
- 横屏模式下取消页面内品牌栏吸顶，组别工具栏恢复正常文档流，标题/操作横向排列，组别独立一行，已有四项摘要保持同一行。列较多的报名表只在表格容器内部横向滚动，操作列可到达；不改正式名单页面的展示约束，不改变报名数据和权限。
- 登录页横屏时为左右分栏：左侧完整竖版LOGO，右侧原微信登录二维码、刷新与教程。使用用户提供原图的既有运行素材，不重画标准字；二维码URL、state、回调和手机号验证未修改。
- 普通桌面登录保持原样；Windows客户端已有本地品牌面板时隐藏新增平板面板，避免两个LOGO面板重复。仍未新增竖屏设计。
