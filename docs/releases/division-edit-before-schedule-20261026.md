# 无赛程时允许修改组别规则（2026-10-26）

用户确认：只要本组没有生成赛程，规则即可修改。规程导入的旧日期、赛事进行中标签、规则定版或竞赛方案标志本身都不代表已经生成赛程。

本次修复基础设置误锁与规则修订入口。后端统一读取当前赛事的实际比赛记录，按稳定竞赛组别ID核对；其他组别不阻断，未排时间的对阵、已取消比赛或轮空记录仍属于已生成赛程证据。归属缺失时阻断核对，不猜测归组。

## 机制

- PC通过webLoginApi的dbQuery/divisionRuleEditState只读操作获取canEdit/hasSchedule/reason；机构、赛事共享范围及模块权限沿既有鉴权校验，远程协助不开放该操作。
- 基础设置和规则向导不再用日期、赛事状态或定版标志判断是否有赛程；状态加载失败或未确认时保持不可保存。
- 已定版但没有赛程时，保存基础设置先通过reviseDivisionRules保留旧版本和规则快照，再保存草稿；不降级原组别模式，不改报名人数校验。
- 规则修订、草稿更新、重新定版三处均在服务端再次核对赛程。页面载入后新生成的赛程也会阻断后续修改。
- 已生成赛程后继续保留既有换人白名单接口；不修改历史赛果、阵容、资格或统计，不删除真实赛程。
- 读取显式分页并处理超过1000条的场景；达到上限或读取异常时明确阻断。
