# Windows 客户端 v0.2.0

2026-10-27。用户要求制作应用图标、将安装后的登录页整理为正式页面，并反馈测试版经常显示“暂时无法连接”。

## 变更

- 应用图标沿用既有蜂与足球图形，清理相邻文字残片，适配浅薄荷绿圆角容器。提供 Windows 多尺寸 ICO、PNG、深色与透明变体、来源登记和预览；属于已有品牌适配，不重做母标志或冒充矢量稿。
- 登录页使用本地可信样式与 DOM 装饰：品牌与扫码两区、正式/测试和版本信息、二维码加载/重试/刷新提醒、操作教程、窄窗口布局。外观仅作用于 Windows 客户端，线上 PC 页面、微信扫码 state、回调、手机号验证、认证清理和业务权限保持原流程；没有另建登录 API、preload 或文件 IPC。
- 修复旧版 `did-start-navigation` 未排除 `isInPlace`：站内 Vue 路由变化会启动 30 秒加载超时，却不再触发 `dom-ready` 清理，导致健康页面稍后被错误页覆盖。这是源码中可复现的缺陷；截图本身没有错误码，不能据此排除其他网络问题。新版本只监测主文档加载，忽略子框架错误与主动取消，防止重放一次性授权码。
- 真实失败显示错误码，可复制最小诊断；本地最多保留 50 条已去除 query/hash、账号和令牌的连接事件。保留正式/测试入口和登录资料隔离。
