# 1.1.29 正式名单默认一人一卡

2026-10-16。用户指出球队赛事中的“正式名单”打开了“选择本届参赛球员”表单，要求逐个球员卡片查看。

## 最终行为

原official-roster路由默认查看模式，按已有officialRoster.snapshot.playerIds去重并匹配授权players资料，每名成员一张纵向资料卡。照片aspectFit完整显示、不圆形裁切；显示姓名、号码、球衣名、年龄、位置以及已返回的本届出场、分钟、进球、助攻、红黄牌。缺失为破折号，真实0保留，缺照片及缺失历史档案分别显示状态；不是新增竞技卡种或自行绘制统一金银铜卡。

只展示该快照成员，不把整个球员库当正式名单。顶部显示草稿/审核中/已审/锁定/退回状态；无快照显示尚未提交及选人入口。草稿和退回名单有权管理者可以明确进入mode=select选人编辑，保留原提交官方名单流程；审核中、已审/锁定不作为随意覆盖的草稿。提交成功转为卡片查看，恢复可见重读原服务，离页或换账号迟到数据不渲染。旧编辑行硬编码U12适龄已删除，避免成人组显示错误。

本次未改云函数、资格、名单快照或统计算法，没有将球员资料自动补为正式参赛资格。卡片使用服务端当前已可返回资料及tournamentStats，不宣称已完成更早历史资料迁移或缺失统计采集。
