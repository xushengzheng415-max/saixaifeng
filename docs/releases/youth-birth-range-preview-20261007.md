# 青少年出生日期自动建议

用户确认 U8 为 8 岁及以下。延续会话明确的按赛事年份计算口径，U8/2026 最早出生为 2018-01-01；未给最低年龄，所以最晚日期留空，可手填。取 competitionYear/seasonYear，次选赛事开始日期年份，不使用电脑当前年份猜测历史或未来赛事。

选择 U 年龄段自动建议出生范围；手动修改最早日期后保留手填设置。年龄上限模式可单独设置最晚出生日期，重新打开保留；成人和非 U 年龄段不生成范围。不宣称该建议属于统一足协标准或按比赛日计算周岁。

test-division-basics.mjs 覆盖 2026/2027、明确赛季年份、U8 包含年界、未知年份/不限年龄不猜测；仅发布 preview/admin，不发布正式后台或函数。
