# 满屏自由战术阵容（2026-11-04）

用户要求战术板以满屏球场为主、工具精简、自由拖拽，双击本方号码选择本队球员并保存阵容；中圈使用提供的赛小蜂Logo。

## 最终行为

- 球队战术板入口直接进入横屏球场，旧列表入口同样转入球场。默认双方11个号码与足球可立即拖动，不必先选阵型、填写名称或逐一绑定球员。整个球场自由摆位，可越过半场。
- 原生movable-area/movable-view承接手势，点位以归一化坐标保存。工具默认收起，含人数、加号码、翻转、清空、阵容方案；保存、返回保留轻量入口，未保存修改返回前确认。
- 本方号码单击不弹输入框，双击才加载本队球员下拉列表，显示姓名与球衣号；选定后关联稳定playerId及显示姓名。重新选择已在场上的球员会交换关联，避免同人重复站位。对方仍仅修改号码。
- 保存战术阵容、球员关联、号码、位置和足球位置，重新打开恢复；服务端重新检查本队归属，并取档案姓名与球衣号，不信任客户端姓名或异队ID。未绑定的纯号码仍可保存。保留旧排阵方案读取及旧验证规则。
- 中圈Logo直接使用用户提供的透明PNG原件，字节未修改，放在球队分包；页面以淡白底纹显示，低于号码与足球层级，不接收触摸事件。
- 使用既有team_tactics，管理权限、团队范围、最多20套及版本冲突校验保持。战术阵容不更改球队成员、赛事正式名单、比赛阵容、审核结果或竞技统计；没有替真实球队保存方案。
