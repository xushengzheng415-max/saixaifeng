# 1.1.26 身份记忆与底部导航

2026-10-16。用户确认工作身份应在同一账号下跨重新打开、更新及退出重登保持；随后反馈手机底部出现两排导航，并指出测试工程打开多个相同窗口。

## 身份记忆

旧profile退出会删除miniPortalRole，App.logout又清空全部存储。现仍清理全部认证和业务缓存，只保留miniPortalRolePreferences/version=1：稳定自然人账号ID映射到team_coach或organizer，不保留手机号、令牌、名单或权限。兼容迁移旧单账号偏好，不同账号分别记忆；只有成功切换才更新。加载中的临时默认身份不写入偏好，退出使在途工作空间请求代次失效。

首次登录没有指定空间时，从服务端刚核验的目录恢复该视角可用空间，保留显式资源点击。失权仍由服务端拒绝，偏好不授予权限；网络失败不改记忆，超时或换账号迟到响应不写缓存。没有改users.role、teams权属、手机号登录协议，也未引入跨设备同步。清除全部小程序数据或换设备不属于本地记忆保证。

## 底部导航

此前个人页恢复底栏时调用wx.showTabBar，手机上出现系统文字导航与自定义图标导航同时显示。现移除个人页全部系统show/hide调用，显隐只交给自定义组件；自定义底栏固定在屏幕底部。身份弹层打开隐藏、取消/成功/离页恢复，保留五个入口和安全区。
