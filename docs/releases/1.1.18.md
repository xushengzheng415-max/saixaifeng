# 1.1.18 首页赛事与球队大卡片

日期：2026-10-16。用户要求当前账号的两支球队与一个共享赛事同时显示在首页，随后要求卡片加大、带背景并使用对应真实LOGO。

## 行为

首页按账号已有授权汇总赛事和球队，替代只显示当前共享赛事的分支。独立卡片展示名称、完整等比LOGO、背景与进入入口；上方左侧共享赛事标共享，球队子账号标管理员，主账号不加身份标签。有封面用已有封面，否则使用现有球场背景；LOGO取已保存的透明版本/文件ID，批量转换云文件地址，图片失败保留入口并显示已有类别占位图。没有创建新球队徽标、修改真实LOGO或复制球员卡绘制逻辑。

getMiniWorkspace新增homeEntries摘要，不把其他空间的teams、球员、课程、消息、财务或统计混入当前上下文。球队来自本人所有权或有效成员关系，赛事来自已验证机构赛事管理或active共享授权；不同稳定ID同名不合并，同一赛事优先已有机构管理入口。当前所有权字段优先于旧owner成员角色。仅有球队关系不能取得整个机构空间，主办方预建队creatorId不当作本人长期球队所有权。完整分页读取所有权与成员资料；读取失败或超预算明确失败。

点击卡片通过已有switchWorkspace切换，回读目标空间与对应资源仍有效，再进入球队中心、赛事详情或共享赛事页。重复点击串行；撤权、缺资源或账号切换时不沿旧卡跳转；登录会话phone-canonical-v1不变。
