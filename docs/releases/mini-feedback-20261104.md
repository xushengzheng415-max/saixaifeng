# 球队小程序接入个人反馈机制（2026-11-04）

用户要求「我的→意见反馈」接入与H5相同机制，并及时同步版本日志。

## 已实现

- 原提示弹窗改为原生反馈页，含提交反馈、我的反馈；分类、10–500字描述、联系微信号、提交频率和通知完全复用H5现有servicePrivate处理器，不复制另一套规则。记录仍在service_feedback，由统一后台处理。
- 按服务端可信小程序OPENID定位已验证手机号自然人账号；请求体账号ID、手机号、OpenID和来源不能选人。兼容phone/phoneNumber及历史微信字段；重复、失效、封禁或冲突账号拒绝。无服务号绑定的球队管理员仍可提交和回查。
- H5与小程序按userId共用记录、待处理/处理中/已处理状态、客服回复及公开教程。只在有效唯一服务号绑定时保存通知通道；没有绑定时仍可在我的反馈查看回复，不承诺微信已送达或已读。列表说明最近50条边界。
- 复用原企业微信提醒，区分真实来源；后台处理链接指向正式独立平台。未新增图片上传要求，保持H5现有字段。
- 客户端处理重复点击、失败重试和换账号的迟到响应，草稿不跨账号保留。使用原生云函数调用，不引入浏览器SDK。
- 源码、当前小程序开发源和实际上传包均为1.2.41（开发版），日志补充1.2.41反馈与1.2.40名单提交两项；我的页与日志页读取同一release配置，不硬编码版本号。
