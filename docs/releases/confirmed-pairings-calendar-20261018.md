# 待排对阵、编号与地图衔接

抽签确认后提供“生成对阵”，演示与真实赛事调用同一纯拓扑模块，日期/时间/场地留空。每个竞赛组别独立连续场序，晋级来源引用原场序；已有历史对阵和排期不覆盖。服务端维持机构、组别、event.draw及已审核球队校验，使用确定比赛ID防重复新增。

整届多组别导出“全部赛程”和组别工作表，沿用现有居中、边框、行高、列宽、冻结和下拉。设置前也能下载空排期表，预设下拉不自动保存成日历资源。导入扫描可见赛程表，同一比赛去重，冲突排期阻断；外部场序映射按组别隔离。

赛程设置保存进入地图并展开左侧待排池；中间按设置日期、开赛时间和场地生成空格，收起抽屉不改变日历。未增加或运行业务测试；构建、发布和线上回读待完成。未写入真实比赛数据。
