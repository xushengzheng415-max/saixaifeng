# 登记赛事卡、即时构图与中断恢复

2026-10-18。用户在球队球员库发出邀请后测试登记，要求使用对应赛事卡、即时调整人像、直接更换图片或重拍，并保留切出微信前的填写进度。

## 实现

- 通过已验证球队的有效参赛关系取得赛事上下文；唯一赛事自动使用，多赛事在表单明确选择。赛事入口固定其原赛事。依据活动状态、不可变模板版本和已发布套系成员选择对应积分卡级，不读取可变草稿，不因赛事卡缺失而套通用卡。没有有效参赛关系时仍走原通用卡流程。
- 登记预览只生成受控的统一动态场景，H5复用 `shared/player-card/draw.js` 的现行同步副本，在固定300×430坐标中绘制；人像大小、上下左右和复位按动画帧在本机更新，不反复请求服务器生成PNG。确认时服务端用同一模板和构图生成最终图并核验指纹、照片、卡级、活动版本、会话及渲染代次。正式提交再次核对模板套系和球队参赛关系。
- 弹窗提供更换图片和重新拍摄；取消选择不清空现有照片，新照片仍走既有百度抠图和私有照片归属校验。登记后的调整页也复用动态场景本机预览。
- 在浏览器原12小时登记会话有效期内保留按邀请入口隔离的会话凭证；新微信授权回调优先处理，不被旧凭证覆盖。表单和照片引用保存在本人私有服务端登记会话，输入防抖、切后台和pagehide提交草稿。版本及选择令牌阻止迟到草稿覆盖新资料；重新打开恢复同一选择、资料、照片和构图，授权不自动勾选，需重新确认卡片。
- 不新建或授予赛事资格/卡库权益，不修改卡级、比赛统计、正式名单或模板；预览卡不是已审核赛事球员卡资格。本人/监护关系仍由原最终登记流程核验。
