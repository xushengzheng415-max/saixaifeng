# 公众专业版抽签大屏原型

## 页面结构

独立公众大屏使用固定赛事头部、全屏状态内容和只读发布页脚。第一阶段包含抽签介绍、球队展示、抽签进行、分组结果、发布撤回、链接无效/过期、断网恢复七个状态。

## 交互与状态

- 主办方后台手动发布后，公众大屏按不可预测令牌读取只读快照。
- 抽签介绍 → 球队展示 → 抽签进行 → 分组结果由已发布快照阶段驱动。
- 撤回、过期和版本替换后不再展示赛事数据。
- 断网状态只保留最近一次已验证快照并自动重试，不接受公众写入。

原型状态参数：

- `?state=intro`
- `?state=teams`
- `?state=drawing`
- `?state=result`
- `?state=revoked`
- `?state=invalid`
- `?state=offline`

## 数据字段

赛事公开名称、竞赛组别、公开球队名称、公开队徽、种子标记、抽签规则摘要、展示阶段、分组结果、主题、版本、发布时间和有效期。

## 素材决策

布局、球场网格、进度、球队卡、组别面板、状态图形与动效全部由 HTML/CSS 绘制；品牌标识复用项目正式 Logo。球队队徽在原型中使用代码绘制占位，正式页面只消费球队明确公开的队徽。

## 素材缺口

无新增生产位图或图标缺口。原型不包含真实球员、监护人、裁判或联系方式。

## 开发边界

本目录是待确认原型，不是正式大屏应用。对应 `_assets` 包获得用户明确确认前，不得开始正式公开路由、快照接口或部署实现。
