# 球员卡自动生成系统 - 使用说明

## 📁 文件结构

```
referee-system/
├── cloudfunctions/
│   ├── imageProcess/              # AI图像处理云函数（抠图）
│   ├── generatePlayerCard/         # 球员卡生成云函数
│   │   ├── index.js               # 核心逻辑
│   │   ├── package.json
│   │   └── painter-palette.js      # Painter 2.0 模板配置
│   └── ...
├── cloudresources/
│   └── cards/                     # 卡片模板（需上传到云存储）
│       ├── gold-card.png
│       ├── silver-card.png
│       └── bronze-card.png
└── miniprogram/
    └── pages/identity/            # 球员卡生成器界面
```

## 🚀 部署步骤

### 第一步：上传卡片模板到云存储

1. 打开**微信开发者工具**
2. 进入「云开发」控制台
3. 点击「存储」→ 上传以下文件：
   - `cloudresources/cards/gold-card.png`
   - `cloudresources/cards/silver-card.png`
   - `cloudresources/cards/bronze-card.png`
4. 记录每个文件的**云存储地址（cloud://...）**

### 第二步：部署云函数

1. 右键 `cloudfunctions/generatePlayerCard`
2. 选择「上传并部署」
3. 等待部署完成

### 第三步：配置环境变量（如有千问API Key）

1. 在云函数配置中添加：
   - 变量名：`QWEN_API_KEY`
   - 变量值：你的千问API Key

### 第四步：安装Painter组件

1. 在小程序根目录执行：
   ```
   npm install miniprogram-painter
   ```
2. 在 app.json 中引入组件：
   ```json
   {
     "usingComponents": {
       "painter": "miniprogram-painter/painter"
     }
   }
   ```

## 🎮 使用流程

### 球员卡生成器界面

1. 进入「身份卡」页面
2. 点击「球员卡生成器」
3. 填写球员信息：
   - 姓名、球衣号、位置、球队
   - 国籍（默认中国）
   - 身高、体重
   - 籍贯（省/市/区）
4. 上传球员照片
5. 点击「生成球员卡」

### 自动生成流程

```
球员注册/完善信息
       ↓
调用云函数 generatePlayerCard
       ↓
┌─ 读取球员数据（数据库）
├─ 处理球员头像（下载→裁剪→AI抠背景）
└─ 生成Painter模板JSON
       ↓
小程序端接收模板
       ↓
┌─ 下载卡片背景模板（云存储）
├─ 下载处理后的头像（云存储）
├─ 下载队徽（云存储）
└─ 下载国旗（CDN）
       ↓
Painter组件渲染卡片
       ↓
生成最终球员卡图片
       ↓
上传到云存储 + 更新数据库
```

## 📐 模板布局说明

基于金卡数据.png（1696x2528像素原图）

| 元素 | 位置 | 说明 |
|------|------|------|
| 号码 | 左侧顶部 | 超大字号，200rpx |
| 位置 | 号码下方 | 52rpx |
| 姓名 | 中间偏左 | 90rpx，加粗 |
| 球衣名 | 姓名下方 | 42rpx |
| 国旗+国籍 | 下方偏左 | 80x56rpx |
| 队徽 | 左侧中上部 | 110x110rpx |
| 身高/体重 | 下方区域 | 38rpx |
| 籍贯 | 最下方 | 30rpx |
| 头像 | 右侧区域 | 340x440rpx，抠图后 |

## 🔧 常见问题

### Q: Painter组件不显示？
A: 确保已执行 `npm install miniprogram-painter` 并在 app.json 中引入

### Q: 头像没有抠背景？
A: 检查是否已配置 QWEN_API_KEY 环境变量，或暂用原图

### Q: 卡片背景不显示？
A: 确认已将卡片模板上传到云存储，并替换模板中的URL

### Q: 文字位置不对？
A: 模板基于1696x2528原图设计，Painter中使用rpx单位，已按比例换算
