# 赛小蜂足球 1.0.27 版本记录

更新日期：2026-08-31
当前状态：正式版已发布

## PC 后台

- 微信扫码首次验证手机号，后续唯一账号可直接登录。
- 球队邀约、专属注册、球队认领和报名二维码统一切换为正式版。
- 正式邀约支持下载二维码和复制完整小程序链接，去除体验版水印和测试提示。
- 赛程、裁判管理、竞赛规程与日程发布等近期优化已发布到正式 PC 后台。

## 小程序 1.0.27

- 手机号作为自然人唯一账号凭证，微信 OpenID/UnionID 仅作为渠道标识。
- 加强账号、机构、球队、岗位和业务数据隔离。
- 修复切换手机号后可能残留上一账号球队信息的问题。
- 完善球队邀约、报名、认领、任务中心和赛事详情流程。

## 裁判服务

- 裁判先关注“赛小蜂足球助手”，再从服务号消息进入裁判登记。
- 支持裁判证高精度 OCR、印章发证机关识别、证书风险提示。
- 支持二寸照比例裁剪、灰度人物对齐模板和百度人像分割去背景。
- 裁判资料页展示二寸照和受限裁判证原图。
- 虚拟裁判可直接用于当前赛事测试排班，不开放登录、通知和真实执裁。

## 发布说明

- 小程序版本号：1.0.27。
- 2026-09-05 已由产品负责人确认最新版小程序正式发布。
- 球队邀约、专属注册、球队认领和报名二维码均使用正式版小程序环境。
