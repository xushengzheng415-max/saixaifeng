# 赛事共享授权操作规范

适用对象：赛事主办方、受邀赛事工作人员。本文是 PC 账号分发、受邀账号接收和线下交接的统一说明。线上入口提供本文件的打印版；纸质件可由主办方直接交给受邀人员。

## 授权范围

- 授权按自然人手机号账号、机构、具体赛事和侧边栏模块记录。
- 共享权限只覆盖被选中的赛事和模块，不等于加入主办方机构，不开放该机构其他赛事、球队或经营资料。
- 一个人可同时拥有自己的机构赛事和其他机构共享的赛事；两类赛事在自己的赛事空间并列显示。
- 共享账号使用自己的登录账号，不共用主办方密码。服务号绑定与赛事授权分别管理。
- 每个共享赛事卡片只显示一次“共享赛事”标识。

## 主办方分发

1. 在 PC 登录主办方账号，进入“账号管理”并选择“分发账号”。
2. 选择具体赛事，填写受邀者已验证的手机号和姓名，再勾选允许使用的侧边栏模块。
3. 保存后状态为“待接受”。保存表示邀请已创建，不代表对方已经获得可用权限。
4. 将本说明或纸质件交给受邀者，提醒其使用分发时填写的手机号登录并接受邀请。
5. 在“账号管理”查看待接受、有效或已停用状态；需要变更时修改权限，停止访问时停用授权。

## 受邀者接收与使用

1. 使用邀请手机号登录 PC。
2. 点击顶部带数字提示的“赛事邀请”；也可打开账号管理，查看“待接受邀请”。
3. 核对赛事名称和授权模块后，点击“接受邀请”。手机号不一致时不要代替他人接受，请联系主办方修改邀请。
4. 接受后回到“赛事空间”，打开标有“共享赛事”的卡片；页面只开放获得授权的模块。
5. 返回赛事空间可切换本人赛事与共享赛事。返回只切换工作空间，授权仍有效。

## 本人赛事与共享赛事

尚无本人机构的受邀账号，可从赛事空间选择“创建我的赛事”，先建立自己的机构，再创建和管理本人赛事。该流程不会覆盖共享授权，也不会把主办方机构变成本人机构。本人赛事与共享赛事会同时出现在赛事空间。

## 权限变更与安全

- 服务端在每次读取和写入时重新核验用户、机构、赛事、动作及授权状态。
- 页面隐藏入口不等于授权；已停用的授权即使留有旧页面，也不能继续操作。
- 不转发账号密码，不把登录验证码、访问令牌或共享账号借给他人。
- 遇到赛事名称、手机号或权限不符，先停止操作并联系主办方核对。

## 线下交接

主办方可在分发账号前打印此说明或另存为 PDF，与赛事名称、联系人和本次授权模块一并交给工作人员。纸质交接不替代系统邀请和本人在线接受；最终权限以账号管理中的有效授权为准。
