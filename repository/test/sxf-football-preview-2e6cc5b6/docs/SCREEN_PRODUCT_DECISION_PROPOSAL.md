# 赛小蜂足球公众赛事大屏待确认方案

> 状态：方案 A 与第一阶段范围已确认；视觉素材包待用户确认
> 日期：2026-08-19
> 适用域名：`screen.sxffootball.cn`

## 一、当前事实

- 已批准和验收的是主办方 PC 内的“大屏设置/预览”节点。
- `ProfessionalDrawFlow.vue` 会生成 `https://screen.sxffootball.cn/draw/:tournamentId?divisionId=...`，但该地址目前没有对应页面。
- 正式路由表只有受登录保护的 `/tournaments/:id/draw`，没有公开 `/draw/:tournamentId` 路由。
- 当前没有独立公众大屏应用、公开只读快照接口、发布令牌、撤回或过期机制。
- `screen.sxffootball.cn` 当前没有 DNS、证书或托管路由。

因此，大屏不是单纯的 DNS 配置任务，需要先确认产品范围和公开数据边界。

## 二、待确认选项

### 方案 A：独立公众大屏应用（推荐）

- 新建独立的 `screen` 静态应用，不加载后台导航、登录状态或管理组件。
- 第一阶段只展示专业版抽签现场。
- 主办方在后台明确执行“发布到大屏”，生成可撤销、可过期的只读快照。
- 大屏只通过发布令牌读取快照，不查询赛事、球队或成员原始集合。
- 后续可独立增加赛程、实时比分和颁奖场景。

优点：公开边界清晰，页面轻量，后续大屏场景可独立演进。
代价：需要新增应用入口、快照接口、域名证书和部署目标。

### 方案 B：PC 应用增加公开大屏路由

- 在现有 Vue 应用中新增不带后台框架的公开路由。
- 仍使用发布快照和令牌，不复用主办方会话。
- `screen` 域名需要路由到同一构建包并保证资源 base 兼容。

优点：复用 Vue 组件和构建体系。
代价：后台与公开页面耦合，`/admin/` base、路由和域名映射更复杂，误带管理能力的风险更高。

### 方案 C：暂缓公众大屏

- 保留后台内全屏预览。
- 不配置 `screen` 域名，不向用户展示无法访问的外链。
- 待完整范围确认后再实施。

## 三、推荐的第一阶段范围

若选择方案 A，建议第一阶段固定为：

```text
主办方完成抽签设置
  → 生成大屏预览
  → 明确点击“发布到大屏”
  → 生成当前赛事 + 当前竞赛组别的只读发布快照
  → 大屏按发布令牌展示抽签介绍、球队展示、抽签过程和结果
  → 主办方可撤回或重新发布新版本
```

第一阶段不包含：

- 赛程大屏、实时比分、颁奖或广告轮播；
- 球员实名、身份证、监护人、手机号、裁判联系方式；
- 主办方后台编辑、数据库直查或匿名写入；
- 用赛事名称、球队名称或公开 URL 参数推断数据归属。

## 四、公开快照最小数据

建议公开发布记录只包含：

- `publicationId`、不可预测的公开令牌摘要；
- `orgId`、`tournamentId`、`divisionId`，仅用于服务端边界校验；
- 赛事公开名称、组别公开名称、公开队徽和球队展示名称；
- 抽签规则摘要、阶段、当前展示状态、分组/签位结果；
- 主题、布局、动画、声音等大屏显示配置；
- `version`、`status`、`publishedAt`、`expiresAt`、`revokedAt`；
- 服务端生成的只读快照，不返回长期球队、成员、球员或赛事管理记录。

禁止进入公开快照：

- 负责人、监护人、裁判手机号和微信标识；
- 实名、身份证、人像原图或受限文件 ID；
- 机构私有经营数据、未审核名单、内部异常原因；
- 后台权限、会话令牌、数据库集合名或可写操作参数。

## 五、接口与授权边界

按项目网页端零 SDK 规则，浏览器仍只调用 `webLoginApi`：

- 主办方动作：创建发布、更新显示阶段、撤回发布；必须通过网页会话、当前机构、赛事和组别权限校验。
- 公众动作：按不可预测令牌读取 `published` 且未过期/未撤回的快照；只返回公开白名单字段。
- 公众端不接受数据库集合名、查询条件、赛事 ID 直查或任何写入动作。
- 令牌只保存摘要；撤回、过期或版本替换后旧令牌立即失效。
- 所有发布、撤回和版本切换记录审计人、时间与前后版本。

## 六、页面与验收

至少需要以下正式状态：

1. 抽签介绍待机页；
2. 球队展示；
3. 抽签进行中；
4. 分组/签位结果；
5. 发布已撤回；
6. 链接无效或已过期；
7. 网络中断与自动恢复。

目标分辨率建议至少覆盖 1920×1080 和 1366×768，并验证全屏、缩放、长队名、队徽缺失、32 支球队、8 个小组和断网恢复。
