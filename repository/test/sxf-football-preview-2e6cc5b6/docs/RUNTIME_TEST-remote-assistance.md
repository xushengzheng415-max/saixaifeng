## 一、本次要验证的问题

1. 平台端生成的协助码能否被**被协助人本人**在 PC 上核对并确认。
2. 确认后平台端进入协助模式时，数据范围是否**只**收窄到该用户的机构/赛事/球队，而不是全平台。
3. 协助期权限 `view / edit` 生效、`delete` 是否始终关闭。
4. 撤销或到期后，协助模式是否**立即**失去访问能力。
5. 审计是否落库（`assistance_audit_logs`）。

范围外：不改产品规则、不改价格/权限定义、不部署、不清理生产数据。

## 二、前置条件

| 项 | 要求 |
|---|---|
| 平台端 | 平台管理员账号密码，入口 `https://www.sxffootball.cn/admin/#/platform-login` |
| 被协助端 | 一个**真实主办方**账号（手机号登录），且**至少创建过 1 场赛事或 1 支球队**，否则协助范围验证没有样本 |
| 账号隔离 | 两侧必须是**不同手机号**。同一账号会命中 `不能接受自己发起的协助申请`（`platformOwner/index.js:287`） |
| 浏览器隔离 | 两侧需要**两套独立会话**：一台电脑平台端 + 另一台电脑/手机热点下的浏览器，或用无痕窗口 + 另一个手机号登录 |

| 时长 | 建议 `2 小时` 档，便于中途到期观察 |
| 时间 | 协助码 `10 分钟` 有效（`CODE_TTL_MS`），发起后要尽快把链接发出去 |

> 本次不提供 shell 权限，因此第六节的**服务端侧核验（HTTP 探针 / 云函数读回）暂不执行**；先完成 UI 全链路，服务端证据等终端放开后补。

## 三、联调步骤（4 段）

### 第 1 段：平台端发起（平台管理员本人操作）

1. 打开 `https://www.sxffootball.cn/admin/#/platform-login`，用平台管理员账号登录。
2. 进入**平台运营中心**（页面标题「运营总览」），左侧最下「返回赛事空间」旁进入**系统管理** `/system`。
   - 也可直接从运营总览 →「问题与协助」→「发起一次协助」。
3. 填写**协助原因**（必填，≤120 字），选择时长，点「生成微信客服协助码」。
4. 记录并回传给我：
   - 协助码显示的 **8 位数字**（只在对话里给我，我会用于联调比对；**不要写进任何文档或截图外传**）
   - 「复制客服话术」生成的 **PC 确认链接**（形如 `…/admin/#/assistance?code=XXXXXXXX`）
   - 页面显示的**协助码截止时间**

**本段核对点**
- [ ] 协助码恰好 8 位数字
- [ ] 话术里链接带 `code=`，且域名为正式域名、路径为 `/admin/#/assistance`
- [ ] 截止时间为当前时间 +10 分钟量级

### 第 2 段：被协助端核对与确认（由你扮演「用户」）

1. 在**另一套浏览器会话**打开那条 PC 确认链接并登录主办方账号。
2. 页面应为「远程协助授权」，协助码**自动填入**并**自动核对**（`AssistanceAuthorization.vue:160-162`）。
3. 核对信息卡显示的：协助人员、协助原因、时长、权限、协助码截止。
4. 点「同意协助」→ 二次确认弹窗「同意后，赛小蜂工作人员可在有效期内查看、添加和修改您创建的资料，但不能删除。」

**本段核对点**
- [ ] 未登录时被要求登录，登录后**回到本页并带入协助码**
- [ ] 无机构的主办方账号也能进入本页（不被机构引导拦截）
- [ ] 协助原因/时长/权限与平台端发起时一致
- [ ] 确认后“我的协助记录”出现该条，状态为**协助中**，可点「立即撤销权限」

### 第 3 段：协助期内验证权限边界（平台端）

平台端在协助记录里进入协助模式（`SystemAdmin.vue` → `setAssistanceContext`），然后**在协助模式下**逐条验证：

| 编号 | 操作 | 期望结果 |
|---|---|---|
| B1 | 查看球队/赛事/球员列表 | **只**出现被协助账号名下的机构、赛事、球队、球员 |
| B2 | 新建一条临时数据（如一张测试球队/球员） | 允许（`permissions.edit === true`） |
| B3 | 修改 B2 数据 | 允许 |
| B4 | 删除任意球队/球员 | **必须失败**，提示删除受限（`webLoginApi` 协助分支拒绝删除） |
| B5 | 尝试读取另一家主办方的数据 | 被过滤，不可见 |
| B6 | 尝试分配竞赛组别等被禁操作 | 被拒（`ASSISTANCE_OPERATION_DENIED`） |
| B7 | 平台端自行「撤销协助」 | 协助记录状态变为已撤销 |

### 第 4 段：撤销 / 到期收口

1. 由**被协助端**点「立即撤销权限」并确认。
2. 平台端刷新协助记录：该条应为**已撤销**，协助模式应自动退出（`SystemAdmin.vue:390-393`）。
3. 再尝试一次 B1/B3 操作 → 应回到无授权状态或超出范围被拒。
4. 另起一条协助申请，**不确认**，等到 10 分钟后再核对 → 应显示**已过期**，且不能确认。

**本段核对点**
- [ ] 撤销即时生效（无需重新登录）
- [ ] 过期申请无法再被确认
- [ ] 协助模式退出后不残留 `assistanceContext`（`cloud.js` 的 grantId 不再随请求发送）
