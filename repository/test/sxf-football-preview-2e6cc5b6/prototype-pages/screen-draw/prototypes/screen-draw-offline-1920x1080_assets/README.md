## 页面结构

## 交互与状态

断网时只展示内存中的已验证快照；恢复后重新校验令牌、版本和状态。 公开页面不提供编辑、登录或数据库查询入口；撤回、过期和断网均有独立可见状态。

## 数据字段

只消费赛事公开名称、竞赛组别、公开球队名称/队徽、种子标记、抽签规则摘要、阶段、分组结果、主题、版本、发布时间和有效期。

无新增生产位图或图标缺口。球队队徽缺失时使用代码占位；不使用原型裁片冒充队徽。
