# 微信开发者工具问题排查

## 检查1：项目是否正确识别云开发

看你的项目目录结构：
```
referee-system/
├── cloudfunctions/     ← 这个文件夹存在吗？
│   └── user/
│       ├── index.js
│       └── package.json
├── miniprogram/
│   └── ...
└── project.config.json
```

## 检查2：project.config.json 内容

确保包含：
```json
{
  "cloud": true,
  "cloudfunctionsRoot": "cloudfunctions/"
}
```

## 快速解决方案：试试这个

1. **关闭微信开发者工具**
2. **重新打开项目**（选择 `C:\Users\27303\Desktop\足球赛事系统\referee-system`）
3. **点击左上角的「详情」按钮**（就在关闭按钮旁边）
4. 在弹出的面板里找 **"本地设置"**
5. 勾选 **"启用云开发"**
6. 如果提示未开通，点击开通
